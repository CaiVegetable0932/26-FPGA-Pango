# GH2 PG2L100H portable routing release

This standalone FPGA release contains the verified GH2 design, 327 frozen inputs, PDS 2022.2-SP6.4 MAP, original review evidence, and one-use external PnR/min-max STA tools. It does not contain unrelated MCU/host development history.

Start with [the external routing and monitoring handoff](fpga/release/gray_GH2_20261101/README_交接.md). The immutable manifest inputs are authoritative. GH2 has passed functional/SYN/MAP/netlist review; physical routing, timing signoff, and hardware tests remain pending. No bitstream is included.
