# MCU 固件布局

`longmenjia/` 是 F4 龙门架工程，保留原 D36A 四路步进工程并增加 PC、F1 代理和 FPGA 独立串口网关；`yuntai/` 是 F1 云台工程，保留原 JOHO 两轴云台工程并增加基于舵机编码器位置反馈的零位确认和 F4 代理链路；2026-10-21 同步后不编译或调用 MPU6050 驱动。`common/` 提供版本 2 外层帧、CRC、有限接收器、持久启动代次和舵机角度换算（保留独立 IMU 参考测试）。

F4 的 PC 入口把旧 `wake/measure/set/go/out/state/stop` 文本语义封装在经过 CRC/会话检查的 `LEGACY` 报文中执行；FPGA 会话只读状态、配置、计数和同步。裸文本与版本 2 报文不混用。F1 的 USART1 是 F4 代理链路，USART3 仍是现有舵机总线。

新增的全系统紧急 STOP 外部命令及内部转发已取消；原驱动的按轴 `stop n` 和本地超时/报警取消动作仍保留。

MPU6050 的 I2C1 PB6/PB7、0x68 和旧采样配置仅作为历史参考；当前 F1 不初始化该驱动。引脚、电平、安装变换、零偏、阈值、权重和稳定判据必须在实际板卡上回读和调试，当前构建没有宣称硬件验收。
