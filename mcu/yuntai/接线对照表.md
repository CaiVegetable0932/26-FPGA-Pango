# 二维云台总线舵机验证接线

## 串口连接

本程序使用两个独立的 115200、8 数据位、无校验、1 停止位串口：

| STM32F103C8T6 | CubeMX 信号 | 连接对象 | 用途 |
|---|---|---|---|
| PA9 | USART1_TX | USB-TTL 转换器 RXD | 上位机命令回显和结果 |
| PA10 | USART1_RX | USB-TTL 转换器 TXD | 接收上位机命令 |
| PB10 | USART3_TX | 半双工转接板 TX/DI | 舵机协议发送 |
| PB11 | USART3_RX | 半双工转接板 RX/RO | 舵机协议接收 |
| GND | — | USB-TTL、转接板和 STM32 GND | 必须共地 |

USB-TTL 转换器必须使用 3.3 V 逻辑电平。PB10/PB11 不能直接短接成舵机 DATA；舵机协议为半双工总线，必须使用已有的自动收发向转接板或三态收发器。转接板标有 TX/DI、RX/RO 时，按上表连接；具体 DATA 端接法以转接板丝印和说明为准。

## 舵机电源和总线

| 对象 | 连接 |
|---|---|
| 转接板逻辑电源 | 按转接板说明供电；不要把电机电源接到 STM32 3.3 V |
| 两个舵机 V+ | 独立、稳定的舵机电源，电压按舵机型号说明书，电流留有余量 |
| 两个舵机 GND | 接舵机电源负极，并与 STM32/转接板信号地共地 |
| 舵机 DATA | 两个舵机并接到同一条总线，不能把两个舵机分别接到 USART1 |

25 kg 舵机的额定电压必须以该批次型号说明书为准；本程序不假定可以由 STM32 或 USB-TTL 供电。上电前先确认转接板输入端和舵机 V+ 的极性、额定范围及峰值电流。

## 默认地址和首次设置

每次上电，USART1 自动读取舵机 ID 寄存器，确认 ID1 和 ID2 都可响应且状态字无报警，然后输出 `READY`。本次串口记录已确认这两个地址均可响应，`scan 1 2` 返回 ID1、ID2 且状态 `0x00`。启动只读核验，不会重写 EEPROM 地址或让舵机移动。若任一只缺失/报警，会输出 `NOT READY`；修复后发送 `ready` 重试。

控制映射保持：pitch 是轴1、串口ID1；yaw 是轴2、串口ID2。因此 `move 1` / `move 2` 参数不变。`get`、`ping` 和 `torque` 的参数仍是串口ID。无角度的 `move AXIS` 保留原有10°往返测试；带角度的 `move AXIS DEG` 从当前读数相对移动，完成后保持在新位置，不自动返回。

只有恢复出厂或地址冲突时才手动使用 `setid`。改ID时必须在总线上只接一只舵机，并在重新上电后确认两个ID不冲突；正常运行和每次启动都不会自动改ID。`map AXIS ID` 是易失的维护命令，默认不要使用，以保持 pitch/yaw 与实际 ID 的编号约定。

## 当前测试命令

在连接 USART1 的串口终端中输入命令并回车：

| 命令 | 作用 |
|---|---|
| `move 1` | 读取轴 1 当前位置，正向移动约 10°，到位后返回原位置 |
| `move 2` | 同上，控制轴 2 |
| `move 1 0.1` / `move 1 -0.1` | pitch（ID1）相对增加/减少约0.1°，在新位置停留；可连续微调 |
| `move 2 0.1` / `move 2 -0.1` | yaw（ID2）相对增加/减少约0.1°，在新位置停留 |
| `ready` | 重新检查 pitch/ID1、yaw/ID2；只有两者正常才启用 move 命令 |
| `get ID` | 读取并打印指定 ID 的原始位置和名义角度 |
| `ping ID` | 读取 ID 寄存器，确认指定地址有应答 |
| `scan [首地址 末地址]` | 扫描舵机地址；全范围扫描最长约 27 秒，期间不要输入其他命令 |
| `status` | 查看轴 ID 映射和运动阶段 |
| `map AXIS ID` | 修改轴到舵机 ID 的 RAM 映射 |
| `ov [AXIS]` | 取消运动并保持当前位置；不保证在一个字节时间内急停 |
| `torque ID 0\|1` | 关闭或开启扭矩；开启时先保持当前角度 |
| `help` | 打印帮助 |

例如从当前机械位置开始缓慢找边界：重复输入 `move 1 0.1` 或 `move 1 -0.1`，每次等待回显完成后再输入下一条；到位后用 `get 1` 记录 pitch 的 `raw` 值，并由上位机标记为 `min`、`max` 或 `center`。yaw 使用 ID2。可输入 `help` 查看命令格式。微调命令不会自动回到原位，角度暂按270°名义行程换算，实际方向受舵机安装方向影响。0.1°约换算为1.52计数并取整为2计数（名义约0.132°）；机械行程与角度映射尚未标定。舵机上电后会回到断电前位置，因此不要用断电手动摆位作为测量流程。

## 角度换算限制

协议位置寄存器是 `0..4095` 原始计数，不携带机械角度单位。当前程序暂按 HLU-I25/RLU-I25 的名义 270° 行程换算，1°约为15.17计数；因此 `0.1°` 会舍入为2计数，最小可表达步长约0.066°。`get` 输出的角度标记为 `nominal`，不能替代后续基于实测最大、最小和对正角度的标定。
