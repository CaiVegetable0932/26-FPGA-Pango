## 当前线协议（以本机代码和字节测试为准）

外层 `55 AA / version=2 / cmd / seq:u16 / length:u16 / payload / CRC16`、profile `0x4D32`、STATE 96B、GET_CONFIG 264B 均不变。XYZ 继续是软件步数估计的归一化坐标，未改成编码器实测。

| 字段 | 当前行为 |
| --- | --- |
| pitch/yaw | `round((servo_raw - center_raw) * 270000 / 4095)`，signed mdeg；中心分别 1881 / 2405。是舵机编码器位置反馈相对机械中心，不是独立相机姿态或绝对航向。 |
| STATE 52 / 56 | pitch/yaw `i32`，mdeg。 |
| STATE 91 angle_source | 每轴 2 bit：1=舵机反馈；双轴有效为 `0x05`，失效轴为 0。不能将整个字节写成 1。 |
| STATE 93 pose_status | 当前双轴纯舵机有效时为 3；未确认零位为 1。 |
| STATE flags | pitch/yaw 仍分别 bit3/4，zero_valid bit6；IMU bit5 不置位，offset24 `imu_capture_us=0`。 |
| STATE 60 angle_capture_us | 已映射到 F4 时间域的有效舵机反馈中较早时刻；不是报文到达时间。时钟映射近似标志 bit11 继续保留。 |
| sample_seq | F1 内部每次有效舵机反馈递增；F4 外部 STATE sample_seq 仍是 F4 发布计数，二者不可混称。 |
| GET_INFO | feature_flags bit1 清零，有持久 boot_id 时 `0x3D`，无有效 boot_id 时 `0x1D`；`imu_type=0`。 |
| GET_CONFIG 角轴 state_source | 2=编码器反馈，与 STATE 的 angle_source 单轴值 1 是两套枚举。XYZ 保持 state_source=1。 |
| GET_CONFIG 68 / 72 | 居中容差 1582 mdeg，对应 24 raw counts；旧上游文档的 ±12 / 792 已不匹配实际容差。 |
| GET_RAW_IMU | 保持 32B 结构；仅 config_version 保留，其余时间、采样号、传感器值、valid 全零。不会把舵机采样计数伪装成 IMU 采样。 |

F1 不再初始化/轮询 MPU6050，固件不编译 MPU/I2C 驱动。保留源码与独立参考测试不表示运行时启用。回正后需两轴连续 5 秒在中心 ±24 raw，反馈新鲜度 20ms；显式读取失败或越界重启稳定窗口。软件中心、方向、相机外参及时间映射仍需独立实板验收。

F1 内部原诊断区中的 sample/config 元数据仍可存在；真正 accel/gyro/temperature/valid 与 IMU 时刻为零。不能照抄上游“60–91 全部为零”的概括。
