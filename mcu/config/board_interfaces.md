F1 新增 I2C HAL 文件复制自本机 `C:/Users/ROG/STM32Cube/Repository/STM32Cube_FW_F1_V1.8.7/Drivers/STM32F1xx_HAL_Driver` 的 `Src/stm32f1xx_hal_i2c.c` 和 `Inc/stm32f1xx_hal_i2c.h`，与工程原 SDK 一致，不依赖参考目录编译。厂商许可原样保留。

F4 启动代次日志保留在片内末端扇区 10/11，链接脚本将应用 Flash 限制到 768 KiB；F1 使用末端保留页并将应用限制到 62 KiB。烧录必须仅擦写应用区，整片擦除会删除启动代次；首次部署应归档 device_id 与代次。如已有其他保留区，先复核烧录布局。
