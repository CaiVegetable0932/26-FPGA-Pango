# MCU 与测试系统开发区

这里直接开发云台、电机、光照控制和配套测试系统。当前仅建立目录骨架，不预设尚未确认的 MCU 型号、SDK、引脚或构建工具。

| 目录 | 内容 |
| --- | --- |
| `firmware/` | MCU 工程、云台与电机控制、光照控制、驱动和通信固件 |
| `host/` | 测试上位机、串口控制、采集、质量与性能测评程序 |
| `tests/` | 固件、通信、测试系统集成与端到端测试 |
| `config/` | 测试设备配置、协议配置和标定参数 |
| `scripts/` | 固件构建、烧录、测试执行与数据处理脚本 |
| `data/` | 实测数据、采集证据与测试记录 |
| `build/` | 本开发区构建结果和中间文件 |
| `reports/` | 实际执行测试后的测评报告 |
| `release/` | 固件、上位机发布产物、配置与版本记录 |

需求、接口设计、测评方法和验收计划写在 [output](../output/README.md)；固件、上位机、自动化代码及其运行结果都写在本目录。FPGA RTL、仿真及算法参考模型写在 [fpga](../fpga/README.md)。

现有[可控光照箱与上位机测评方案](../output/可控光照箱与上位机测评详细实施方案.md)中未来生成的证据目录，统一放在 `mcu/data/` 下；生成报告放 `mcu/reports/`。规划中的示例不是已经执行的测试结果。

本区脚本应根据自身位置解析路径，避免依赖终端当前目录。所有子目录均受当前 Git 规则管理；`.gitkeep` 只用于保留空目录，可在添加实际文件后移除。
