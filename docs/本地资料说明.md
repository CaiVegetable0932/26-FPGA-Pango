## 引入正式设计的规则

1. 从资料中复制所需 RTL、IP 配置、必要生成源码、仿真模型、约束和初始化文件到受控目录；保留原版权和授权说明。
2. 在相应 IP 或模块旁记录原始资料路径、IP/工具版本、复制日期、修改项和必要文件 SHA-256；明确目标板卡。
3. 修复绝对路径，使正式构建不依赖被忽略的 `reference/`。
4. 提交前核对依赖完整性；`.hex`、`.mem`、`.dat`、`.idf`、`.pds` 等输入文件不按扩展名统一排除。

请另行把整个 `PDS/` 和 `reference/` 复制到独立磁盘或受控备份位置。若决定将某批资料纳入 Git，应先调整忽略规则并评估容量；不要直接强制添加整个资料目录。
