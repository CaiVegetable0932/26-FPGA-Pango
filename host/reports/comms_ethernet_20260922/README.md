## 重启与复现

当前Flash镜像上电仅初始化PHY，不默认发送。每次冷启动需使用fpga/scripts/prepare_comms_boot.py生成新epoch和明确PC地址，通过host/scripts/comms_uart.ps1下发0x70；不要重放此次已使用的boot命令。接收器应在发送配置前启动；正在发送时可重新打开接收器，但首尾半帧不作为丢帧验收样本。启动/接收脚本均只保存JSON诊断、计数和哈希，不保存视频内容。

本次epoch3971348597321107983已使用。结束测试后PC接收器与串口均已关闭，板卡继续发送至本机已配置地址；断电/复位会停止并清除配置。没有再次烧录或改变板卡配置以隐藏缺包。
