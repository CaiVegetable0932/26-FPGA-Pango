## 覆盖的行为

1. 真实回环UDP接收和HTTP二进制帧读取，CRC与非指定来源过滤，u64最大epoch和大于2^53的源帧身份保持为字符串。
2. 启动、重复启动拒绝、采集时配置锁定、停止、重复停止、重启后新run_id与源帧身份、过期画面不再作为新帧保存。
3. 手动与自动归档，原始metadata下载与像素SHA-256核对；重复保存不覆盖，磁盘写入失败显式停止，手动归档队列拒绝有独立计数。
4. 模拟发送子进程随会话启动/停止；发送端口占用会成为可见错误，不会一直显示假正常。
5. Host/Origin/token、控制请求体长度、内容类型、路径访问和静态资源白名单。
6. 四种Bayer排列、1080p彩色/灰度、RGB888、损坏数据及极宽窄图的缩放边界。
