# RAW8 浏览器缩放格点修复（2026-09-27）

- 用户提供的同一网口预览截图中，缩小画面有细密暗格点，放大后减轻。当前冷启动会话仍持续收到完整 1920×1080、`RENH`/版本 2、板侧增强 Bayer RAW8；2026-09-27 检查时约 29.6 完整帧/秒、帧龄约 15 ms。此现象优先定位为浏览器缩小逐 Bayer 样本灰阶画布产生的相位混叠，不以截图证明传输字节损坏。
- 原 `RAW 灰阶` 模式把 1920×1080 每个 Bayer 样本直接画入 canvas；网页卡片仅约半宽，浏览器再次缩小时会不均匀选取不同 Bayer 相位。现由画布实际显示宽度决定：仅在缩小显示时，预览 worker 按完整 2×2 Bayer 单元取均值，形成 960×540 派生灰阶供 CSS 绘制；全尺寸浏览/无显示宽度参数时仍保留逐样本模式。板侧位流、PRAW 包、接收帧、`.raw` 归档与测量数据均不改；主机不重复应用 FPGA 亮度曲线。
- `node host/tests/test_pixels.cjs`：11/11 通过，新增半宽 Bayer 相位抗混叠与原字节哈希不变回归；`PYTHONPATH=host/src python -B -m unittest host.tests.test_webui`：20/20 通过。运行中的 `http://127.0.0.1:8766/pixels.js` 已提供新逻辑，`Cache-Control: no-store`，硬件接收仍为 live。用户现有页面需刷新，以加载新的 Web worker；实际浏览器视觉消点效果仍待用户审校。传感器自身的细噪声不属于此显示缩放修复。
