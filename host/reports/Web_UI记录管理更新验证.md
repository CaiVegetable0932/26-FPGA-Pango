- Python协议与Web集成：52项通过，失败0，错误0，跳过0；[测试结果](webui-records-tests.json)。
- 前端记录操作：3项通过，使用隔离DOM夹具验证选择/取消、确认前不删除、运行与子图像去重、部分失败保留选中项和再次操作；[测试结果及记录脚本哈希](webui-records-frontend-tests.json)。

- [静态引用检查](webui-records-static-checks.json)核对双路同级视频面板、共享16:9规则、控件ID、资源文件和更新文档链接；不属于浏览器实测。

## 删除与索引覆盖

索引测试构造了111条图像目录记录、37次运行和独立报告，确认不再受100张图像、30次运行上限影响；没有结束报告的运行仍出现在列表中。

通过真实HTTP测试确认：单图删除只移除该图及元数据；整轮删除同时移除该轮data/reports；同时选择父运行和子图像只删除一次；独立报告可下载和删除；一批中出现非法目标或当前采集运行时，在删除前拒绝整批。模拟文件占用时返回部分失败结果，并支持后续重试。

目录边界与递归删除检查拒绝越界、符号链接和Windows目录联接。链接测试注入链接判定，不依赖Windows创建符号链接的权限；所有实际删除仅发生在host/build/内经绝对路径验证的临时夹具。

## 页面行为与范围

S0与S2/S3是同级面板，桌面等宽并排，窄屏上下排列，画面统一16:9，标题、信息行和页脚高度一致。连接信息置于下方。蓝白主题使用深蓝文字、白色面板、浅蓝背景和蓝色活动态，删除/错误保持红色提示。

当前Web会话正在采集的记录不可选择删除。界面会显示删除范围并要求在对话框内确认；取消操作清除待执行删除。文件实际从本机工作区删除，原运行报告中的历史“写入帧数”不随单张图像删除而改写。

HDMI视频后端依然未接入，结果区显示真实未接入状态。Ubuntu24.04、浏览器视觉/交互和真实硬件验收未执行；本次仅确认代码、接口、隔离前端状态与本机HTTP可用。历史Web UI/PRAW报告保持原验证时点，不能以它们的旧源码哈希证明本次改动。
