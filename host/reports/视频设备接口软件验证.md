## 覆盖行为

| 场景 | 软件检查结果 |
| --- | --- |
| 配置无需信号 | 只枚举视频输入；选择、保存与恢复不调用 getUserMedia，不创建视频轨道 |
| 指定输入 | 打开使用已保存的 deviceId exact，audio=false；设备不存在、被占用或权限拒绝时保留配置，不回退到其他摄像头 |
| 临时授权 | 枚举成功或失败后均释放临时流；授权成功不自动开始预览 |
| 取消与退出 | 取消后迟到的流立即停止；页面销毁释放流和监听，避免设备持续占用 |
| 无数据与断连 | 轨道静音显示等待，结束/移除释放流；状态始终不升级为信号验证通过 |
| 浏览器限制 | 存储不可用时保持当前页选择；不支持摄像头的窗口提示使用系统浏览器 |
| 页面控制 | 保存与打开分开，未保存的选择禁止打开；设置区与右侧预览共用同一个控制器 |
| 后端边界 | 新资源返回正确类型，媒体策略仍限本机；Python 的 HDMI 原始采集 available=false，源帧身份 null/unverified |

测试没有访问操作系统的真实设备枚举，没有打开 Hagibis，没有抓取或检查实际图像，没有新增真实采集证据。浏览器交互、实际 UVC 驱动、无信号时的驱动行为和 Ubuntu 24.04 实机兼容尚未验证。
