# 板卡上电后启动 host

适用：当前 RAW8 双路固件、板载 CP2102、千兆网口、Hagibis HDMI 采集卡。支持 Windows 与 Linux；当前板端 UART 是 PC 调试入口，不能同时被 MCU 或串口终端占用。

## 首次准备

1. 使用项目 Python 3.12+ 运行 `python host/scripts/setup_calibration.py`，安装标定和串口依赖。已有 Jetson 环境先执行 `source host/scripts/env.sh`。安装只写项目虚拟环境。
2. 确认直插摄像头、USB-UART、网线、HDMI 和采集卡连接，开发板完成上电。网线接到 PC/Jetson 的指定网卡。
3. 在系统网络设置中给直连网卡设置 IPv4，例如 PC `192.168.80.2/24`、页面中的 FPGA `192.168.80.3`。已有可用地址可继续使用，两端须在同一子网。FPGA 不实现 DHCP/ARP/ping，不能用 ping 不通判断此链路故障。
4. Windows 双击 `host/scripts/start_web.cmd`；Linux 执行 `sh host/scripts/start_web.sh`。默认页面 `http://127.0.0.1:8765/`。
5. 在顶部“一键连接”选择 CP2102 和直连网卡，填写 FPGA IPv4；MAC 默认 `02:00:00:00:00:01`，UDP 默认 PC 50000 / FPGA 50001。PC 的 IP/MAC 由实际网卡读取。
6. 首次在“连接设置”授权并选择 Hagibis，保存设备；外部 PotPlayer 等需释放采集卡。点击“启动 / 重连板卡链路”。首次浏览器权限仍由用户允许。

“下次启动 host 自动连接”默认勾选，在完成启动配置时保存；下次板卡上电后只需启动同一份 host。成功打开过的视频在预览/标定页面导航时恢复，同一站点其他页面的采集会话会自动释放。显式点击“关闭”会取消视频自动恢复。

## 新启动流程

服务读取保存的设备选择 → 枚举实际网卡与 CP2102 → UART 查询冷/热启动状态 → 绑定 UDP 接收端 → 冷启动时保存新 epoch 并发送 RAW8 配置 → 校验 ACK → 读取摄像头/PHY 状态 → 等待完整网口帧。HDMI 独立打开，网口失败不会阻止它显示。

板卡一直上电、只是重开 host 时，复用本项目保存且与板端查询一致的 epoch，不重复发送新 boot。若配置来自其他电脑/目录、换了网卡地址或 MAC，页面会要求冷启动后重试。ACK 丢失可点击重试；发送前已保存配置，能够查询实际板端状态后继续接收。

页面显示“网口已收到完整视频帧”才表示收到实时完整帧。HDMI“接口打开”仅说明 UVC 设备打开；采集卡自身 No Signal 图案不能作为 FPGA 视频已锁定的证明。HDMI 源帧身份仍为 unverified。

## 预览、标定和测试

- 网口完整帧在左侧显示，可“保存最新完整帧”；原始 RAW8 与元数据保持保存。
- HDMI 在右侧打开。UVC 暂忙时会在同一设备上最多重试两次；USB 重插改变 deviceId 时，仅在已保存名称唯一匹配时恢复选择。
- 点“进入标定”。填写图卡规格、每张图的距离等参数，使用网口抓帧或采集卡保存标定图；标定流程见[标定工作台](标定工作台.md)。手动鱼眼预览仍为 PC 软件参考。
- 网口接收、保存帧、校验/丢包指标独立计数；本轮没有新增自动精度验收或自动下发标定参数。

## 状态与恢复

| 页面现象 | 处理 |
| --- | --- |
| 无 CP2102 / 无法打开串口 | 接数据线、关闭串口终端；Linux 检查 dialout 权限，重新登录使已有组设置生效 |
| 没有直连网卡选项 | 检查网线、USB 网卡及系统 IPv4；列表只列已启用且有 IPv4 的网卡，勿选择 VPN/虚拟网卡 |
| UDP 端口占用 | 同一个服务内重试会释放自己的接收器；其他 host/接收程序需停止，服务不会任意杀进程 |
| 摄像头未就绪 / 未发布帧 | 检查直插连接、供电与冷启动；host 不会通过合成图隐藏板侧问题 |
| 状态就绪但没有 UDP | 核对网卡、地址、防火墙及板端网线链路 |
| 有包但没有完整帧 | 查看丢包/CRC/组帧统计及 Linux 接收缓冲；不自动更改系统设置 |
| HDMI 设备忙 | 同站点页面可移交采集占用；外部 PotPlayer/其他浏览器来源需关闭。12 秒未完成打开会退出并允许重试 |
| 板卡已锁定其他配置 | 停止后给板卡冷启动，再点击重连；不能在运行中替换网络地址或 epoch |

配置保存在 `host/config/board-link.json`、`host/config/board-link-boot.json`；每次启动的串口收发与结果保存在 `host/reports/board-link-*.json`。这些含本机设备与地址的运行记录不作为通用示例提交；仓库忽略规则不变。

原流程需要手工生成 boot JSON、在 Web 填参数并另外运行 Windows PowerShell。新入口完成这些衔接；旧[手动启动说明](RAW8双路候选启动与预览.md)保留为低层联调参考。
