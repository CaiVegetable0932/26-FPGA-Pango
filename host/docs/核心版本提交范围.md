# 核心版本提交范围

2026-10-06，按用户要求，本轮仅提交上位机核心实现与运行所需构建文件，不上传此次联调与测试生成的数据。

## 纳入版本

- `host/src/`、`host/web/`、`host/scripts/`、`host/tests/`：实现、启动与构建脚本、复验工具和测试源码。
- `host/config/`、`host/docs/`、`host/README.md`：连接及服务配置、依赖说明、操作与实现说明。
- `host/build/udp-fast/`：批量 RAW8 处理模块及源码/二进制哈希清单。
- `host/build/uvc-diagnostic/`：Hagibis 实际使用的修复模块、对应源码与补丁、匹配的 Seeed 基线源码/模块、原厂回退模块，以及安装器读取的 `payload-build-check.json`。该 JSON 是构建兼容性清单，不是图像采集数据。

UVC 模块仅适用于已核对的 ARM64 `5.15.148-tegra` 内核与原厂模块指纹。迁移或升级 JetPack 后不得直接加载旧模块；应重新核对来源、内核 ABI 和安装脚本的检查条件。

## 留在本机

本轮新增的 `host/data/` 原始帧、录像、元数据和采集日志，以及 `host/reports/` 截图、实测与软件测试报告全部留在本机。第三方安装环境、浏览器个人会话、下载归档、其他 UVC 诊断候选和编译中间文件也不纳入此次提交。原有已提交的历史文件保持不变，不删除本地文件，不新增 `.gitignore` 规则。

实现说明中标为“本机留存”的报告路径用于定位这台设备上的记录；新克隆不会包含这些记录。用户需要新的证据时，可运行随版本提交的复验工具生成。
