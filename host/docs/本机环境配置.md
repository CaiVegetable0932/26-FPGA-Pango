# Jetson 本机 host 环境

配置日期：2026-10-02。机器：Ubuntu 22.04.5 LTS、Jetson ARM64、5.15.148-tegra。已完成本机 Web 上位机的软件环境安装与实际浏览器检查。验证记录见 [本机报告](../reports/environment_20261002/README.md)。

## 日常启动

在仓库根目录运行：

```bash
sh host/scripts/start_web.sh
```

入口自动使用 `host/build/environment/venv/bin/python`，并在本机桌面打开独立 Chromium。访问地址为 http://127.0.0.1:8765/。已有同目录服务时复用该服务；页面关闭后后台采集仍需通过“停止”按钮收尾。

从任意目录也可以运行本机绝对路径：

```bash
sh /home/cai/26-FPGA-Pango/26-FPGA-Pango/host/scripts/start_web.sh
```

命令行开发、测试及采集工具使用项目环境：

```bash
source host/scripts/env.sh
python --version
node --version
ffmpeg -version
v4l2-ctl --version
```

`PANGO_PYTHON` 可显式选择其他 Python 3.12+；`BROWSER` 可显式选择其他浏览器。项目启动器依次查找显式解释器、项目虚拟环境、`python3.12`、`python3`，并检查版本。

## 系统准备

已通过本机管理员授权完成：

- `/etc/sysctl.d/90-pango-host.conf` 设置 `net.core.rmem_max=16777216`，当前值已生效；接收器请求 8 MiB 时，Linux 返回的含记账开销缓冲值为 16 MiB。
- `cai` 已加入 `dialout` 组。当前桌面会话的旧进程仍保留旧组列表，重新登录后串口组权限生效。
- 本机已在 `video` 组中。

截至检查时，USB 未枚举到 CP2102 或 Hagibis，`/dev/video*` 与 USB 串口均为空，`enP8p1s0` 有线网口为 DOWN。设备接入后重新枚举物理身份、网卡地址与链路；不要复用旧 Windows COM 号、MAC/IP 或冷启动 epoch。

浏览器视频预览走跨平台 `getUserMedia`。现有 `comms_uart.ps1` 和 `hdmi_diag_capture.py` 的 PowerShell/DirectShow 路径仍属于 Windows 工具；安装 pyserial、FFmpeg 并不会自动把这些工具变为 Linux 后端。Linux 上的实际板端启动控制及 HDMI 原始证据采集需按后续平台适配验收。

## 服务管理

本次已由用户 systemd 管理后台服务 `pango-host.service`，无需保留开发工具的终端。查看和停止：

```bash
systemctl --user status pango-host --no-pager
journalctl --user -u pango-host -n 40 --no-pager
systemctl --user stop pango-host
```

这是用户会话内的服务。退出登录或重启后，可继续使用上述一键启动命令；需要后台运行时从本机仓库目录执行：

```bash
systemd-run --user --unit=pango-host --collect \
  --description='Pango host local workbench' \
  --property=Restart=on-failure \
  --property=WorkingDirectory="$PWD" \
  /usr/bin/sh "$PWD/host/scripts/start_web.sh" --no-browser
```

先停止服务再修改运行代码。正常停止会排空采集与归档。

## 重建与验证

本机安装脚本可重复执行，固定 Python、Node、uv 与 Python 依赖版本，下载包经官方校验，Ubuntu 多媒体工具以包方式解到项目目录：

```bash
sh host/scripts/setup_environment.sh
```

重建系统准备项需要本机管理员身份，用户名按实际登录用户填写：

```bash
sudo sh host/scripts/configure_linux_system.sh cai
```

环境和软件验证：

```bash
source host/scripts/env.sh
python -B host/scripts/check_environment.py
python -B host/scripts/test.py --report host/reports/environment_20261002/python-tests.json
node host/tests/test_pixels.cjs
sh host/scripts/start_web.sh --no-browser
python -B host/scripts/check_browser.py --headed
```

浏览器检查只允许当前仓库、未运行采集、显式 mock 配置的本机服务；它会创建独立的模拟运行记录及一张原始 RAW8，检查保存与 SHA-256 后停止该模拟。正式硬件帧率、来源证明和 HDMI 配对均需设备接入后另验。

安装依据：[uv Python 管理](https://docs.astral.sh/uv/guides/install-python/)、[Node.js 官方校验清单](https://nodejs.org/dist/v22.23.3/SHASUMS256.txt)、[Playwright 浏览器安装](https://playwright.dev/python/docs/browsers)。
