# 简单相机标定入口

2026-10-08，合入云端 main `8873a2392b573c67eb988894730e756073993c27` 的新版上位机。
保留新版鱼眼/针孔标定、人工测距、手动鱼眼参考预览及双路采集功能。
完整模型与调参说明见[标定工作台](标定工作台.md)。

## 启动与图卡

Windows 双击 `host/scripts/start_calibration.cmd`；Linux 使用
`sh host/scripts/start_web.sh --page calibration`。默认打开
`http://127.0.0.1:8765/calibration`，可加 `--port 8767` 指定其他端口。
Windows 优先使用已有 `host/build/calibration-venv/`；首次准备依赖使用
`python host/scripts/setup_calibration.py`，该入口同时安装串口依赖。
本次 Windows 同步保留本机 receiver 配置；云端 Jetson 的 board-link、启动纪元
和硬件输入状态仅留在拉取副本中，不作为这台 Windows 机器的运行配置。

按用户最新确认，默认棋盘格为 **21×21 内角点、10 mm 格长**，即22×22方格，
完整检测应有 **441个角点**。新建组需填写相机、镜头、图卡、焦点、平整度、
测距参考面和固定采集模式；已有组配置冻结，更新软件不会改写原组参数。

模型由操作者选择：针孔输出 `D=[k1,k2,p1,p2]`、固定k3=0，符合当前FPGA
受限模型；鱼眼等距输出 `D=[k1,k2,k3,k4]`，这四个系数不兼容当前针孔寄存器。
两种模型在参数摘要中使用各自的名称，程序不自动下发硬件参数。

## 图像入口

每张新样本都填写其真实镜头参考面—图卡距离；光照、曝光、角度和位置可记录，
未知项保持未知。人工记录不等于MCU同步遥测，也不作为OpenCV内参拟合的约束。

1. 已有上位机原图：刷新“当前上位机已保存原图”，选中完整RAW8/RGB888记录，
   填写该图对应的测距信息，再点击选入。后端验证完整性、行跨度、字节数和SHA-256，
   保留来源清单；不会修改原归档。
2. 当前网络流：在采集工作台启动真实摄像头接收，再到标定页点击抓取网口当前帧。
   后端从同一接收器冻结1秒内完整帧，无第二个UDP监听器，不使用缩小后的预览。
3. 采集卡/摄像头：授权、选择正确设备、打开预览，逐张保存原分辨率RGB。
   输入应是几何矫正前的画面；不能用已矫正的HDMI S2/S3重新拟合镜头。
4. 本地文件：每次导入一张PNG/JPEG或无行填充RGB888，并记录对应测距值。
   RGB需准确宽高，可附JSON元数据。PNG/JPEG保留上传字节和派生RGB。

RAW8按协议 `1=RGGB, 2=GRBG, 3=GBRG, 4=BGGR` 以原分辨率去马赛克，分别保存
`image.raw`与派生`image.rgb`。原始哈希和来源元数据保留，基础转换没有几何变换，
不认证与FPGA S1等价。已知TEST/MOCK合成图和已声明S2/S3的样本会被拒绝。

## 检查、求解与导出

采集至少25张有效拟合图，建议25～40张，另留至少3张不同的独立验证图。
完整棋盘格清晰入镜，改变位置、距离和两个方向的倾角，覆盖中心和四角。
点击样本名称看角点叠加；只有全部预期角点检测成功才计入有效样本。
剔除需记录原因，不删除原图。25/3是软件下限，赛题没有规定该数量或RMS通过线。

求解后直接显示模型、分辨率、fx/fy/cx/cy、正确命名的四系数、训练RMS和逐图
独立验证RMS。可下载完整版本化JSON与SHA-256，历史结果可点击“查看参数”。
独立验证只估计外参，不重新拟合K/D。旧版针孔组缺少model或人工测距字段时，
沿用针孔模型、距离保持null并提示记录缺失，不改写原样本。

证据在 `host/data/calibration/<组ID>/`，报告在
`host/reports/calibration/<组ID>/<版本ID>.json`。新增来源接口为
GET `/api/calibration/sources` 和 POST `/api/calibration/record`、`live`；后者携带
`dataset/role/manual`，记录选入另带`key`，沿用会话token与本机来源校验。

所有结果为candidate_unverified、measurement_ready=false、hardware_applied=false。
来源等价性、独立直线度/MTF/SFR、任意角度动态映射、FPGA插值、帧率/延迟及资源
验收仍需对应实现和真实测量。手动软件参考不替代实时FPGA链路。
