# Host 镜头与相机标定工作台

入口：启动 `host/scripts/start_web.cmd`（Linux 用 `host/scripts/start_web.sh`），打开本机 `/calibration`。如未安装可选依赖，运行 `python host/scripts/setup_calibration.py`；依赖锁定在 `host/requirements-calibration.txt`，只安装到 `host/build/calibration-venv/`，不修改系统 Python。网页与视频接收器共享本机服务，但标定求解不会更改 FPGA 位流、寄存器或 MCU 状态。

## 外部输入及冻结范围

创建标定组时填写：镜头模型（鱼眼等距四系数，或针孔 k1/k2/p1/p2）、棋盘内角点/圆点行列、实测间距 mm、图卡编号和平整度、相机与镜头编号、焦点、固定采集模式，以及**镜头到图卡测距所采用的机械参考面**。若只量到镜头前端而不知道光心偏移，应照实记录；不要把机械距离伪称为已知光心距离。换镜头、焦点、裁剪、镜像、Bayer 相位或 ISP 模式需新建标定组。

每张拟合或独立验证图都必须人工输入该姿态下参考面至图卡平面的**实测距离 mm**；可填测距不确定度、光照预设 1/2/3、实测照度 lx、曝光时间 μs、云台 Roll/Pitch、龙门架 XYZ 和备注。空白可选项保留为 null，不补造测量值。这些字段标记 `manual_unverified`，不是 MCU 同步遥测；距离暂不作为 OpenCV 内参拟合约束，只用于完整的实验记录和后续独立核查。

## 采集、求解与证据

- 可使用网页采集卡的原生分辨率画面，或逐张导入 PNG/JPEG/紧密排列 RGB888。每次只导入一张，避免把同一测距值误配给不同姿态。网口接收器运行时，“抓取网口当前帧”仅接受最近 1 秒的完整硬件 RAW8 帧，保存精确 `image.raw`、派生 `image.rgb`、角点预览和元数据；不按 CSS 缩放图像参与角点检测。网口增强 RAW8 及浏览器解码帧均不自动等价于 FPGA 几何前 S1。
- 每组至少 25 张有效拟合图、3 张不同的独立验证图。检测失败、重复、尺寸/来源冲突的图仍归档但不参与求解；手工剔除保留原因。拟合不自动删除高误差图。报告包含 K、D、逐图重投影误差、4×3 角点覆盖、人工距离、源图哈希和候选版本哈希。
- 鱼眼求解使用 OpenCV fisheye 等距模型 `D=[k1,k2,k3,k4]`；针孔求解固定 k3，使用 `D=[k1,k2,p1,p2]`。两种模型系数不可互换。鱼眼结果标记 `fpga_compatible=false`，**不得直接下发**当前 FPGA 针孔寄存器；标定报告仅为 `candidate_unverified`，不声称板端矫正完成。
- 原始/派生图在 `host/data/calibration/<组ID>/<样本ID>/`，版本化 JSON/SHA-256 在 `host/reports/calibration/<组ID>/`。浏览器中的源帧号只是来源声明，`source_frame_id` 与 HDMI 同帧身份仍为 null/unverified，直到独立协议验证。PNG 角点图不能代替原图证据。

## 尚需实测

当前新增功能通过合成棋盘、鱼眼投影和 HTTP 路由软件测试；换上的实物鱼眼镜头仍须采集足够覆盖边缘、不同距离与倾角的真实图卡图像。还需验证图卡尺寸/平整度、S1 几何等价性、独立网格直线度和目标 FPGA 鱼眼算法/参数解析。不能用训练重投影误差代替这些验收项。

## 手动鱼眼参数与实时软件参考

应用户要求，`/calibration#manual-preview` 增加单独的 PC 软件参考预览。它不改变正式视频主链路、FPGA 结果窗口或已有标定记录，不下发镜头参数。预览来源可选择当前已打开的采集卡，也可选择已保存的样本（即使该图角点检测失败）。左、右窗口共享同一张 RGB 输入，右侧通过鱼眼逆映射和双线性采样显示近似校正效果。直播源停止更新时报告等待/中断；冻结帧与保存样本均显式标注。

默认采用用户于 2026-10-02 审校截图确认的组合：“用户审校 · 200°鱼眼”，参考 **1920×1080**，`fx=770`、`fy=752`、`cx=945`、`cy=553`，`k1=0.121`、`k2=-0.118`、`k3=0`、`k4=0.036`，输出水平视场为 **139°**。可导入备份位于 `host/config/calibration/fisheye-user-reviewed-20261002.json`。浏览器已有合法的手动值时保留上次值；如需恢复该组合，选择“用户审校”并点击“应用预置参数”。修改或恢复的参数不匹配任何预置时，选择框显示“当前手动 / 上次保存参数”。

仍保留通用 **200°对角视场、等距投影**假设（`fx=fy≈631.086 px`、中心主点、零系数、110°输出），以及 180°对角等距和 200°对角等立体角近似。通用焦距按 `hypot(W,H)/(2×100°弧度值)` 计算；等立体角预置由 `2 sin(theta/2)` 的多项式展开给出。这些都是参考假设，不等于实物镜头测量；用户审校组合亦未经过标定精度验收。

改变焦距、主点、k1～k4、输出水平视场的数字或滑块会立即更新；输入未完成或曲线产生折叠时暂停校正预览并提示原因。内参以“参数参考宽高”为单位，当前画面不同尺寸时按像素中心缩放，仅对本页预览生效。采集卡的缩放/裁剪关系仍需单独核验。畸变公式遵循 [OpenCV 4.13 鱼眼模型](https://docs.opencv.org/4.13.0/db/d58/group__calib3d__fisheye.html)，零畸变系数在该模型下代表等距鱼眼，并不表示输出恒等图像。

调参值保存在浏览器 localStorage，也可通过“导出调参 JSON”备份、再导入本页。文件使用 `pango.fisheye-preview.v1` 独立格式，标记 `manual_approximate / pc_software_reference / fpga_compatible=false`；不与真实求解报告混用。该页不自动写入原始采集样本、实测图像或训练标定参数。WebGL 支持时以输入分辨率渲染，预览上限 20 FPS；不支持时退回最大宽度 640 的 CPU 参考（上限 8 FPS），页面报告实际方式与预览 FPS。这些上限不是相机、网络或 FPGA 帧率验收值。
