# 上位机开发区

本目录承载PC上位机软件及其配置、采集证据、测评报告和发布产物。当前已建立目录骨架，并补充以下上位机专用需求与开发文档；尚未实现应用程序，也未完成设备联调或硬件验收。

## 实现与产物落点

| 目录 | 内容 |
| --- | --- |
| src/ | 界面、FPGA/MCU客户端、设备控制、采集、标定编排、参考模型适配、质量与性能测评、自动测试 |
| config/ | 设备连接、测试流程、ROI、标定及上位机配置 |
| tests/ | 单元测试、通信模拟、集成、回放与端到端测试 |
| scripts/ | 本区启动、构建、打包、测试和数据处理脚本 |
| data/ | 采集图像、同帧证据、实际参数、事件日志、模型调用中间证据和回放输入 |
| reports/ | 由上位机产生的指标、曲线、测评结果及报告 |
| build/ | 上位机构建结果与中间文件 |
| release/ | 软件发布包、冻结依赖、版本、配置、操作说明与校验记录 |

同一运行的证据在host/data/<run_id>/，报告在host/reports/<run_id>/，通过run_id、版本和哈希关联。已有目录不代表已有业务实现；详细模块路径是后续开发建议。

## 与其他开发区的边界

- [FPGA开发区](../fpga/README.md)负责RTL、ISP、帧缓存、硬件算法、PDS和位流。浮点与位精确权威参考模型归fpga/model；host适配调用冻结版本，不维护另一套模型源码。
- [MCU开发区](../mcu/README.md)负责云台、电机、灯光、外设驱动和设备端保护。host只负责PC控制客户端和试验编排，MCU型号和SDK仍待确认。
- FPGA资源与时序原报告归fpga/reports；host测评报告可引用或带来源复制，不伪造重新测量。
- 原mcu/host/不再使用，PC功能统一归本区；MCU板级数据仍归mcu/data。

## 当前基线与后续第一步

硬件基线为PG2L100H（盘古100Kmini）＋单路OV5640，真实1080p30为交付目标。采用串口融合IMU直连FPGA的方向，具体模块和协议待落实。上位机建议Python、PySide6、OpenCV等方案，实际版本在兼容验证后冻结；当前不代表这些依赖已安装。

先按03文档完成H1“可靠连接与控制”和H2“同帧证据采集”，然后接入测评与自动报告。无硬件时可以用显式标注的mock/replay推进软件，不计作新的实时硬件验收。
