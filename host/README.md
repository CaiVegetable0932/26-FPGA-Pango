# 上位机开发区

本目录用于独立开发上位机软件及保存运行产物。当前仅建立目录骨架，尚未实现应用程序；语言、界面框架和依赖按后续确认的方案配置。

| 目录 | 内容 |
| --- | --- |
| `src/` | 界面、FPGA/MCU 通信客户端、设备控制、图像采集、质量及性能测评代码 |
| `config/` | 上位机配置、测试流程参数、标定及设备连接配置 |
| `tests/` | 单元测试、通信模拟、集成和端到端测试 |
| `scripts/` | 启动、构建、打包、测试执行及数据处理脚本 |
| `data/` | 采集图像、同帧证据、测试数据与运行记录 |
| `reports/` | 上位机生成的测评结果及实测报告 |
| `build/` | 构建结果与中间文件 |
| `release/` | 上位机发布包、版本、配置与校验记录 |

需求、界面与接口设计、测试计划写在 [output](../output/README.md)；上位机代码及运行结果直接写入本目录。云台、电机、光照的设备端驱动和固件归 [mcu](../mcu/README.md)，FPGA RTL、仿真及算法参考模型归 [fpga](../fpga/README.md)。

[可控光照箱与上位机测评方案](../output/可控光照箱与上位机测评详细实施方案.md)中的采集证据统一放 `host/data/`，生成报告放 `host/reports/`。原 `mcu/host/` 已取消，其工作范围由本目录承接；MCU 板级调试数据仍归 `mcu/data/`。

在项目根目录打开 VS Code 即可同时管理三个开发区。脚本按自身位置解析路径，避免依赖终端当前目录。Git 规则不变：仅排除根目录 `reference/` 和 `PDS/`，本目录全部默认纳入。`.gitkeep` 仅用于保存空目录。
