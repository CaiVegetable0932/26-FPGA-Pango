## 1. 时间、角色与范围

沿用2026-09-05启动、2026-11-04完成两个日历月：8个项目周（每周7个自然日）＋5天交付缓冲。本次架构更新不自动顺延日期。实际启动时间改变可整体平移，休息日由团队安排；本表不是自动提醒或计划任务。

按3类角色规划，可由2～3人或一人兼任，尚未代表已分配人员。所有实现及其产物直接归属`fpga/`、`host/`、`mcu/`；`output/`仅放规划。FPGA浮点/定点模型归`fpga/model/`，PC接收与评测程序归`host/src/`，采集证据归`host/data/`。

| 角色 | 主要职责 | 固定产出 |
|---|---|---|
| A：硬件与视频/网络 | 板卡、DVP、ISP、DDR、RGMII/MAC、HDMI、CDC/时序 | 可重建工程、真实接口/带宽计数、板级时序报告 |
| B：算法与RTL | 逆映射、定点、cache、插值、参数解析、阶段快照、吞吐 | 模型/仿真、阶段对照、综合结果、逐帧记录 |
| C：上位机与测试 | RAW网络重组和基础显示、HDMI采集、标定、控制、测评 | 完整原始帧、真实标定档、同帧证据、质量/性能/能效报告 |

基线为：**单OV5640 RAW8 1080p30 → S0经板载千兆网到PC；FPGA ISP生成S1 → 按off/pre_resample/post_resample完成重采样S2及完整结果S3 → 单HDMI到采集卡/PC。** 两窗保留完整1080p数据，不把图像缩成半屏传输。PC左窗仅做RAW基础显示，不能冒称FPGA S1，也不代替FPGA几何运算。

共同优先级：指定相机真实1080p30 → 完整彩色硬件链和双回传 → 真实标定/几何正确 → 稳定完整30fps → 动态/能效与证据 → 60fps扩展。VGA/720p只用于短期联调，不作为最终达标结果。

## 4. 网络、缓存与快照检查点

以下按[跨端方案](./OV5640_RAW8千兆网与HDMI双路回传方案.md)统一，字段不在本表另创版本。

| 检查项 | 基线 | 验证时间与方法 |
|---|---|---|
| 帧池 | SRC/DST各3×8MiB，RAW3×4MiB，快照S1/结果各8MiB；共76MiB，描述符等另算 | W1定义、W2地址/边界测试，不能继续使用旧64MiB预算 |
| RAW内存/网络行距 | DDR stride2048；网传有效stride1920 | W2逐行去填充、最后行和帧长度核验 |
| 数据包 | IPv4 UDP、MTU1500、64B应用头＋最多1400B数据；应用字段小端，网络协议头按标准 | W2抓包/解析/边界/CRC/错序测试；无IP分片 |
| RAW30线速 | 有效497.664Mbps；计头/前导/IFG等约543.9024Mbps | W2～W4实测队列、包/帧完整率、混合DDR，不把预算当成绩 |
| 快照 | S1＋选定S2/S3同帧、专用槽、低优先级 | W3验证复制/引用/校验；≤1Hz仅条件上限，长稳默认每60秒一组；须测RAW＋快照总压力 |
| 调度 | 采集/处理/HDMI优先，RAW网络其后，快照最后；各类有服务/等待统计 | W3～W4连续流＋突发快照＋网络断线，禁止网络反压DVP |
| 源帧身份 | S0由网络ID确认；HDMI未知为null/unverified | W2起UI和报告强制保留；严格对照只用板端验证快照 |

一组S1/结果快照每秒一次，在上述封包口径下额外约108.7763Mbps，总约652.6787Mbps；还需计控制、重传和实现效率。该数字只说明预算，实际允许频率由DDR、网络和PC共同决定。不能为快照拖慢30fps主链路，也不能丢失RAW后仍标“双路稳定”。

## 6. 功能优先级与工期保护

| 优先级 | 功能 | 工期紧张时 |
|---|---|---|
| P0 必达 | 真实1080p30 RAW输入、FPGA彩色链、真实参数解析、径向/切向、双线性、完整帧管理、RAW30网传、单HDMI30结果回采、同帧快照证据 | 不删除，不改成720p、半幅图、编码压缩或伪配对 |
| P1 主线 | 连续面内角度、按帧参数/pre增强、独立UART姿态、HDMI连续源关联、质量/资源/延迟/能效报告 | 优先板载/上位机指令验证映射；未完成UART适配或连续关联单列，不能以快照冒充连续同源通过 |
| P2 扩展 | 有限透视、1080p60、更高质量ISP、低延迟、高速原图回传 | 未通过单列，不占用最后一周P0回归 |
| P3 后续 | 双目深度、复杂CLAHE、自制主板 | 不进入两个月关键路径 |

姿态基线为独立融合UART模块直接接FPGA，型号/协议/电平尚待确认，PC控制UART与姿态口分开。PC可做RAW基础显示、标定、参考和控制，但实时参赛几何映射/重采样仍在FPGA。严格精度证据为板端同帧S1/结果；几何测评关闭增强。pre模式源邻域先查LUT再插值，S2已含增强；post为插值后查LUT的独立对照，保存实际LUT与位置，不能互换参考。PC基础显示允许不同ISP，但不能据此判断几何独立误差。低频快照只证明抽样帧，不能替代HDMI连续源关联验收。W5必须实施并独立验收pre_resample；可先跑通post对照，但前置未通过时，预处理目标明确记为未完成，不能移出本次两个月范围。

## 7. 每周固定检查

每周保存一次可运行里程碑。位宽、cache、DDR、网络、时钟或采集格式变化后，运行相应回归，不仅目视画面。

- [ ] 输入/处理/RAW有效接收/HDMI发送与捕获fps、重复/无效/丢帧分别统计。
- [ ] 有效尺寸为1920×1080，RAW字节完整；网络缺包超时作废，不混用上一帧数据。
- [ ] stream_epoch/frame_id/阶段/参数版本清晰；HDMI未知来源仍为null/unverified。
- [ ] SRC/DST/RAW/快照所有权正确，未决DMA读写及发送不会污染已复用槽。
- [ ] 真实K/D可读回，参数仅在帧边界生效；模式不符、溢出、CRC错误可验证拒绝。
- [ ] 恒等、边界、跨块、正负角度与RAW Bayer相位测试通过。
- [ ] 包CRC、offset/长度、乱序、PC重连和源采集代次切换、采集卡丢帧测试有证据；PC重连不改写在途帧/快照的stream_epoch，源重启/模式变更在帧边界更新。
- [ ] cache填充字节、DDR/网络等待、FIFO水位、最坏帧时间与快照限流可追溯。
- [ ] 整机PDS资源、WNS/TNS/未约束路径包含网络和快照模块。
- [ ] 标定图、相机/ISP模式、参数和位流版本一致；稳定版可恢复。
- [ ] 功率测量边界明确，能量/帧以有效处理帧计算，不按重复显示帧计算。

## 9. 演示脚本

1. 显示真实输入尺寸/fps、千兆链路、RAW完整帧率、处理fps和HDMI采集模式。
2. PC左窗标“S0 RAW基础显示”，右窗标实际S2/S3回采；两份数据保持完整1080p。HDMI源ID未知时显示未验证配对，不宣称30对/秒连续同源对比完成。
3. 下发/读回真实K/D，触发板端同帧S1＋结果快照，展示经校验的严格对照及有效视场。
4. 连续改变角度，停在45°/90°，查看直线与实时计数；不把PC做的参考图当硬件视频。
5. IMU零位后缓慢转动相机；记录曝光/帧时间对应与残差。
6. 改变照明，展示pre_resample增强与post_resample独立对照；记录LUT及位置，S2可能已含前置增强，严格几何测试关闭增强。
7. 展示整机资源、实际处理/回传fps、延迟及能效；若60fps通过，切换真60源和对应标定，并逐项说明回传能力。
8. 装载真实参数后退出PC软件、断开网线和控制线，FPGA独立供电并向独立显示器输出，响应板载旁路/矫正/旋转按键；若采用分配/环出，其供电与EDID须保持。记录此时网络断连，恢复后回到稳定配置，不把容错丢帧算成长稳通过。
9. 展示内部坐标、四邻域/插值权重、帧完成及同帧快照对照，说明正式位流和调试位流差异。未实现非易失参数加载时，不声称断电后无需PC即可恢复标定配置。
