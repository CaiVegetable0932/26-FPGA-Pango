# 06 ISP 与几何矫正优化方案

V1.0，2026-10-12。专项优先级：**性能 > 时序 > 资源消耗**。在相同像素质量、完整帧与误差要求下提升吞吐；不以省乘法器、降位深或降插值阶数牺牲目标。

## 1. 当前状态与入口

先读[总览](README.md)、[主设计](../PG2L100H_1080p畸变矫正详细设计方案.md) §5～7、[跨端方案](../OV5640_RAW8千兆网与HDMI双路回传方案.md)及[整机测评](../可控光照箱与上位机测评详细实施方案.md)。

已有[IP集成模块](../../fpga/rtl/memory/ip_integration_bank.v)及[IP参数目录](../../fpga/config/ip_catalog.json)提供资源，不是完整算法：

| 资源 | 当前配置/作用 | 缺失业务逻辑 |
| --- | --- | --- |
| `isp_line_ram` | 2048×32 bit，简单双口 | RAW窗口、边界和延迟对齐 |
| `tile_cache_ram` | 32768×32 bit，128 KiB候选数据RAM | 标签、bank、命中、替换、miss/重放 |
| `parameter_ram` | 1024×32 bit真双口 | 实体解析、影子区、按帧版本 |
| `gamma_rom` | 512×8 bit，两页identity | 有意义的校准/增强LUT与版本 |
| `geometry_mult` | 有符号25×18，流水乘法 | 完整坐标公式与定点范围 |
| `bilinear_multadd` | 两路18×9乘积相加 | RGB四邻域完整插值和最终舍入 |
| `statistics_mac` | 16×16乘法、48 bit累加 | 按帧/ROI统计与结果锁存 |

诊断路径仍是摄像头内部ISP输出的RGB565；不能把它当FPGA S1。正式RAW8→FPGA基础ISP→S1→矫正/增强→选定结果尚待实现。主设计96 KiB cache数据预算与当前128 KiB候选RAM不一致，需按端口和实测命中重新比较，不照名字强行收缩或外推资源。

## 2. 分工与算法边界

本区可在内部交接为ISP、坐标流水、cache/插值、增强/统计四条工作线，但必须使用共同的像素/tag、定点和参数契约。无需新造外部协议。

- ISP：黑电平/钳位、分颜色增益、3×3去马赛克、固定白平衡/可选色彩矩阵，输出可追溯的S1。
- 坐标：输出→源逆映射，合并镜头畸变、旋转/缩放及已定义透视，避免多次重采样。
- cache/插值：四邻域寻址、二维缓存、miss服务、RGB双线性与有效掩码。
- 增强：统一`disabled/pre_resample/post_resample`，LUT实体按帧锁定，统计有帧/ROI边界。

RAW Bayer必须先经过正确的去马赛克再做通用RGB几何插值，不能直接混合Bayer不同颜色位置。镜头阴影校正不是几何去畸变。

## 3. 性能与精度目标

| 项目 | 目标/口径 |
| --- | --- |
| 首要吞吐 | 真实1080p30，62.208 Mpixel/s完整有效输出 |
| 初始流水 | 150 MHz，目标II=1；内存停顿和尾部排空另计 |
| 帧服务预算 | 每帧33.333 ms，按实际源间隔调整；不能仅看平均II |
| 定点坐标误差 | 主设计RMS≤0.05 px、max≤0.25 px，有效域全域核验 |
| 正式像素格式 | S1与结果RGB888，保留规定的中间精度 |
| cache效率 | g=实际源回填字节/(3×输出像素数)，计入重复与padding传输 |

150 MHz/II=1下平均有效利用率至少41.472%，这是预算而非完成证明；cache连续miss、输入峰值、参数切换、pipeline排空都要覆盖。资源优化不得突破精度或完整帧要求。

## 4. 性能优先实施路线

### A1 建立浮点与位精确正确性基线

在`fpga/model/`建立与已冻结标定模型一致的浮点参考及位精确模型，明确坐标原点、像素中心、K/Kout/D、裁剪/镜像、Bayer、边界、舍入与饱和。使用实际标定实体；零畸变/identity仅作单元测试，不冒充真实镜头测评。

每个算术阶段列出输入范围、Q格式、符号、乘积宽度、截位/舍入点、延迟与overflow策略。先建立每阶段golden再接整条流水，避免整体误差无法定位。

### A2 ISP连续像素流水

两行RAM与窗口寄存器形成3×3窗口，支持四种Bayer排列与合法边缘扩展。黑电平/增益/色彩处理分级，不把窗口RAM读延迟、行末flush或边界像素算成漏帧。

02输入同时分流到RAW DMA与ISP；S1写入与帧身份交03/04。不能为方便新增RAW整帧DDR读而不计流量。输入不可暂停时，ISP/缓冲给出峰值服务及整帧错误策略。

### A3 坐标并行流水

行列递推减少重复仿射运算，按主设计在图块起点重算并控制累积误差。畸变和透视阶段按依赖拆分乘加/范围判断；分母符号、近零、归一化与可表示范围必须处理。

倒数可按主设计比较归一化LUT初值与定点迭代，不先固定迭代次数/位数承诺误差；以模型扫描确定。流水级可增加，tag/valid/参数在停顿时与算术数据一致，保证II目标而不是每级独立快。

### A4 cache与四邻域吞吐

1. 标签/数据/替换状态分开，按访问分布比较tile尺寸、bank和双缓冲回填；不因128 KiB数据RAM已存在就认定cache完成。
2. 设计有界miss队列、请求合并、重复回填抑制、回填写入与读端冲突策略。标签仅在完整有效回填后可命中。
3. 四邻域端口根据实际地址分bank；边界夹取产生重复地址时合并读取或广播，不能假设四个样本总在不同bank。
4. 对不能单拍服务的bank冲突设计明确重放/等待；统计端口冲突、miss、回填量和最长阻塞，验证不会乱序错tag或饿死。
5. 与04联合优化合法DDR行段回填和对齐，按实际g和无服务间隔评估，而不是只比较平均命中率。
6. 强畸变、旋转、缩放及有效域边缘都是压力输入。并行增加算术单元后同时重算cache端口、回填和结果写流量，不能宣称自动线性提速。

### A5 插值与增强

RGB双线性分水平/垂直阶段，中间不提前裁为8 bit，最后一次舍入并钳位；负坐标floor与向零截断区分。有效闭区间与邻域夹取按主设计，identity保留末行/末列。

`pre_resample`在四邻域RGB查表后插值，最多12次独立通道查表/输出像素；`post_resample`为插值后3次。优先按II目标提供足够RAM端口/副本，复用方案须证明全部查表服务满足期限。两种模式数值不同，不混用验证。

LUT、几何与姿态参数整帧一致，默认只缓存选定结果。统计累加按帧/ROI清零和锁存，不把占位MAC归约观察位当图像质量指标。

## 5. 时序优先措施

- 拆开乘法、宽加法、归一化、比较/钳位及地址mux，使用APM原生输入/流水/输出寄存；宽运算资源映射以PDS报告确认。
- 高扇出坐标/参数在局部寄存，重算流水尾部与tag延迟；配置时计算常量，逐像素阶段避免长除法或可变大mux。
- cache标签比较、命中选择、bank仲裁和数据读取流水化，加入足够弹性buffer；ready路径长时切分但保持无丢/重复。
- 先目标器件PnR和真实CDC/存储同址语义通过，再做共享运算。01审核proc域、RAM域和外部DMA接口约束。

## 6. 资源第三的允许优化

性能/时序通过后比较位宽收窄、低频参数运算共享、标签压缩、缓存容量与LUT副本数量。每个收窄都用全域误差/溢出模型证明；不能为了APM数把每像素II推高到不达标。

优先使用[IP配置](../../fpga/config/ip_catalog.json)和原生生成器，扩展实例从配置/工程登记，不手改生成HDL。原资源预算属整机，算法不得独占所有RAM/APM；配置位宽不匹配时应提出具体候选并重新综合。

## 7. 接口与修改边界

06拥有算法、cache与阶段有效性；02提供RAW格式/帧错误，03锁定描述符/参数与槽，04提供回填/写回事务，07解析并提交参数实体，05消费完整结果。对miss返回、乱序支持和退出帧的排空共同冻结。

新增模块建议落`fpga/rtl/isp/`、`geometry/`及对应存储/增强模块；模型落`fpga/model/`、TB落`fpga/sim/`。当前IP集成模块保留为占位基线，不将正式算法全塞入其中。共享IP配置/顶层/协议由集成负责人合并。

## 8. 验证与交付

| 类别 | 必测内容 |
| --- | --- |
| ISP | 四种Bayer、首末行列、黑电平/增益极值、窗口flush、已知RAW与位精确RGB |
| 坐标 | identity、真实K/D、正负旋转/坐标、近零分母、边界、溢出与全域误差 |
| cache | 连续命中/全miss、四bank冲突、重复地址、回填覆盖、失效、队列满及随机DDR等待 |
| 插值 | 整数/分数位置、最后一行列、无效域mask、单次舍入与通道顺序 |
| 增强 | disabled/pre/post各自golden、帧中更新拒绝、LUT版本、统计窗口与清零 |
| 混合 | 同步RAW输出、S1/结果DMA、显示、快照和参数切换，完整帧/服务期限 |

报告实际II、有效像素/帧率、stall分解、g、miss/冲突、队列峰值、流水/排队/帧缓存延迟、坐标RMS/max、像素误差、PnR和资源。模型/仿真不能替代实板精度/吞吐，PNG不能替代原始`.raw/.rgb`证据。

正式几何测评用板端同源S1和选定结果快照、真实标定与有效掩码；PC RAW可视化不是S1。报告落`fpga/reports/`或`host/reports/`，硬件操作遵循既有放行。

## 9. 专项智能体任务描述

请按本方案、总览和主设计，以性能>时序>资源实现并优化FPGA基础ISP与逆映射/双线性。先建立浮点和位精确模型、明确Q格式/边界/阶段，再达到完整1080p30及150 MHz/II=1初始流水目标。优先消除cache miss、bank冲突和宽组合运算瓶颈，按实际g和混合DDR服务验证；保留全域RMS≤0.05 px/max≤0.25 px和RGB888要求。pre/post增强分别实现与验收，LUT/参数按帧锁定。交付代码注释、golden/异常回归、吞吐/精度/PnR/资源对比及实板未验证项，共享顶层/IP/协议交集成负责人合并。
