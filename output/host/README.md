当前主方案：同一颗OV5640的S0 RAW8经板载千兆网实时回传PC，FPGA完成基础ISP和畸变矫正后经唯一HDMI OUT与采集卡回传结果。PC只做S0基础可视化，不转发主视频，不用软件几何矫正补位；严格精度测评采用板端S1与S2/S3同帧快照。详见[跨端回传方案](../OV5640_RAW8千兆网与HDMI双路回传方案.md)。

本组文档已同步上述设计；[PRAW网络核心](../../host/docs/千兆网视频协议与上位机实现.md)已有代码和Windows软件验证；[本机Web界面](../../host/docs/Web界面与核心接入说明.md)已接入S0预览、接收控制和证据管理，UART/HDMI适配、Ubuntu实机及硬件验证仍待完成。文中的 host/src/、host/data/、host/reports/ 等是以项目根目录为基准的实现路径，不随文档移动而改变。

跨端依据见 [整机测评方案](../可控光照箱与上位机测评详细实施方案.md)、[FPGA 详细设计](../PG2L100H_1080p畸变矫正详细设计方案.md)及[总开发计划](../两个月开发规划表.md)。
