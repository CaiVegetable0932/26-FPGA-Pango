# FPGA 防抖与矫正图像补全功能优化交接

版本：V1.0。日期：2026-10-13。用途：下一阶段功能设计、任务分工与验收交接，不是实现完成或实测报告。

目标优先级：**性能 > 时序 > 资源消耗**。在真实 1920×1080、30 fps 主视频目标下，优先实现小幅电子防抖、受控裁边，再实现带来源标记的历史背景补全；后续扩展完整透视、相机 IMU 辅助和滚动快门补偿。功能正确、来源可追溯和实际时序收敛是可交付前提。

接手智能体先阅读本文件第 1～4 节和自己的任务包，再复核当前代码。本文不授权自动创建聊天、联系其他智能体、下载位流或操作硬件；任务分配由使用本文的用户或集成负责人安排。

## 1. 架构与当前实现基线

保留单路 OV5640 RAW8 DVP 输入：S0 原始图经板载千兆网回传，FPGA 完成 ISP 得到 S1，再产生几何结果并通过唯一 HDMI 输出。PC 负责配置、离线模型、证据采集和测评，不转发主视频、不执行实时几何矫正。PC 对 S0 的彩色预览不能作为板端 S1。

依据当前工作区源码与 2026-10-12 分区报告，已有能力如下。报告中的结果只适用于相应快照和测试范围，接手者不得以 HEAD 或文件同名替代源码一致性检查。

| 部分 | 已有实现 | 下一阶段缺口 |
| --- | --- | --- |
| 输入与配置 | RAW8 接收、帧完整性判断、分流、SCCB 回读与寄存器实体 | 实物 RAW8/1080p30、真实跨域 FIFO、正式链路接入 |
| ISP | 黑电平、分 Bayer 通道增益、12 bit 中间数据、双线性去马赛克；独立 CCM/统计模块 | 板级 CCM/曲线接入、真实色彩标定、稳定的自动亮度/白平衡策略 |
| 几何 | 仿射递推、23 级镜头逆映射、RGB888 双线性插值、按帧锁参 | 防抖参数生成；完整透视前端接入；强缩小抗混叠 |

## 2. 功能范围与实施阶段

| 阶段 | 功能交付 | 进入后续阶段的条件 |
| --- | --- | --- |
| M0 基础集成 | RAW8→ISP→S1→几何→结果→HDMI，S0 网络支路；异常排空和同源快照 | 联合功能回归、可综合帧池、混合服务预算和完整工程时序；硬件验收按既有放行流程 |
| M1 首版防抖 | 图像平移、小角度画面内旋转、轨迹平滑、补偿限幅、自动裁边；与去畸变合并采样 | 完整帧率、抖动/延迟/视场损失与退化行为达标 |
| M2 有限补全 | 当前帧加前 1～2 帧，优先静态背景，仅补几何缺失区域 | 多源身份、帧池压力、带宽和动态物体误填验收 |
| M3 高阶运动 | 完整透视、相机 IMU 辅助、逐行曝光补偿 | 相机安装外参、时间标定、协议扩展、透视工作域和整机预算通过 |

M1 的角度、平移和缩放范围必须通过全域坐标检查和缓存服务测试冻结，不能只凭“仿射支持旋转”承诺任意角度。M2 不承诺补出所有黑边；从未被任何有效帧观测到的内容无法由历史帧恢复。生成式补全不纳入当前板端交付目标。

模型和局部模块可提前开发；M0 未通过时只能报告相应局部能力。视觉防抖、IMU 防抖和机械云台控制分别定义，FPGA 继续不向 MCU 下发运动命令。

## 3. 统一处理流程

```text
RAW8 DVP
  +-- S0 帧池 --> 原始网络回传
  +-- ISP --> S1 帧池 ------------------------------+
                +-- 低分辨率灰度/特征 --> 运动估计 --+--> 轨迹平滑/补偿限幅
                +-- 历史 S1 保留 -------------------+              |
                                                                  v
标定实体 + 输出视窗 + 防抖变换 --> 联合逆映射 --> 当前帧采样/有效掩码
                                                        |
                            仅几何缺失且允许补全 --------+
                                                        v
                               历史对齐/置信度/遮挡检查/融合
                                                        |
                                结果 + 来源掩码 + 元数据 --> HDMI
```

一次重采样指当前帧的镜头矫正、防抖和裁剪变换联合计算后只插值一次，不是声称历史像素也无需额外读取。不得先生成一整帧矫正图再增加一整帧防抖重采样，除非实测证明该候选在同等画质和整机吞吐下更优。

逆映射按输出像素查找源坐标，本身避免正向投影造成的内部散点空洞。真正视场外区域、算法异常和传输错误分别处理：几何视场外可裁切或补全；溢出、错误地址、DDR 失败仍按帧级错误处理，不能用历史像素掩盖。

## 4. 先冻结的共同接口

以下是建议内部语义，不是已批准的网络字段、命令编号或既有结构布局。A0 组织冻结；外部修改同步跨端权威方案、各端实现与测试。

| 实体或接口 | 必需语义 | 负责方 |
| --- | --- | --- |
| 帧与采集实体 | epoch/frame_id、曝光参考定义与不确定度、尺寸/Bayer、标定/曝光/WB/ISP 版本、slot/generation | A0，复用原 02/03/07 |
| 运动观测 | 源/目标帧身份、变换方向、坐标域与单位、模型类型、匹配质量、有效位、时间戳 | A2；A6 提供独立 IMU 观测 |
| 防抖实体 | 当前→目标视图的明确定义、模型/定点格式、实际补偿矩阵、裁剪视窗、置信度和退化原因 | A2/A3；A1 提供视窗约束 |
| 有效性与来源 | 当前帧有效、历史补全、显示外推、仍缺失；传输/算术失败另有帧级错误 | A1 定义，A3/A5 传播 |
| 历史读描述符 | epoch/frame_id、slot/generation、源参数实体、地址/stride、访问范围、生命周期/取消 | A4 提供，A5 消费 |
| 补全记录 | 每个被用历史帧身份、对齐版本、帧龄、置信度、来源区域；混合时保存可追溯权重或其确定性生成规则 | A5；A0 对接 host |
| 完成语义 | 像素产生完、DMA 可见完成、整帧发布、消费者排空、历史引用释放分离 | A0/A4，保持原 03/04 契约 |

禁止用黑色 RGB 值判断无效区域；黑色可以是真实内容。建议用最少 2 bit 来源类别表达四类显示像素，再独立保存置信度和历史帧引用，2 bit 本身不包含完整溯源信息。

历史补全结果是多源派生图像，不能未经协议定义就冒充原单帧 S2/S3。保留“测量模式”和“视频增强模式”：测量模式默认关闭历史补全/外推，固定或归档实际变换；视频增强模式输出所有来源记录，精度统计分别计算当前帧区域和历史区域。HDMI 普通采集身份继续 `null/unverified`，直到形成明确证据。

## 5. 智能体任务包

### A0 整机集成与验收负责人

**任务：**完成 M0，冻结本文件第 4 节接口，维护共享顶层、工程、公共约束与跨端设计。先解决正式帧池综合未完成的问题，再证明 RAW/ISP/几何/显示/网络同时工作时的生命周期、服务期限和异常恢复。禁止只将模块加入文件列表就宣称集成完成。

**入口：**[主顶层](../fpga/rtl/board/pango_video_top.v)、[帧池契约](../fpga/rtl/memory/README.md)、[DDR 契约](../fpga/rtl/memory/DDR_DMA_CONTRACT.md)、[显示契约](../fpga/rtl/video/README.md)、[原分区总览](FPGA分区优化交接/README.md)。

**交付与验证：**接口冻结表、全链路仿真、源/结果/网络完整帧计数、联合取消/复位测试、post-PnR 资源时序与未约束项、分阶段放行清单。组织 host 独立测评；控制参数按源帧原子生效，模式切换排空，失败明确回退最后有效配置。

### A1 标定 有效区域与自动裁边

**任务：**从真实板端 S1 同源证据复核标定，冻结镜头模型和适用裁剪/分辨率；生成有效性模型和受防抖范围约束的输出视窗。输出模式至少包括保留视场、固定裁剪、受限动态裁剪。

**入口：**[标定候选](../fpga/config/isp_geometry/calibration_source.json)、[镜头逆映射](../fpga/rtl/geometry/lens_inverse_map.sv)、[参考模型](../fpga/model/isp_geometry.py)。新增模型归 `fpga/model/`，采集/光学测评归 `host/`。

**关键实现：**按非线性逆映射验证整个候选有效区及插值边界，不能仅看四角或最大外接矩形；分别表达目标视窗与输入尺寸。动态视窗有缩放上限、变化率、迟滞和补偿饱和反馈。裁剪后内参/坐标变换与测评元数据同步。

**验收：**identity、四边、负坐标、旋转/缩放极值、非居中主点、参数切换；测试有效 ROI 内是否存在漏标无效像素。报告保留宽高/面积比例、缩放变化和细节损失。裁边不称为恢复缺失内容。

### A2 视觉运动估计与轨迹平滑

**任务：**以 S1 分出的低分辨率灰度图为输入，先实现平移，再扩展小角度画面内旋转/相似变换；通过多区域匹配和稳健汇总提取背景运动，输出置信度与异常原因。480×270 只是首轮比较候选，冻结前与更低/更高分辨率对照。

**建议落点：**新 RTL 可置于 `fpga/rtl/stabilization/`，模型与专用测试置于 `fpga/model/`、`fpga/sim/`。它们是待创建路径，不是现有模块。可用 OpenCV 成熟算法建立离线参考；板端选择确定开销的块匹配/稀疏特征实现，不依赖 PC 实时处理。

**关键实现：**缩小前低通；明确在畸变图还是校正坐标域拟合运动，不能把强畸变图中的全局仿射无条件当作理想成像模型。区分逐帧运动、累计轨迹、平滑目标轨迹和实际补偿；保留有意慢速转向，限制漂移和补偿范围。首版只用当前及过去帧，记录完整运动估计完成时刻，禁止默用未来帧获得低抖动指标。

**验收：**静态、已知平移/正负旋转、缓慢平移叠加抖动、低纹理、大前景运动、遮挡、曝光跳变、切镜/重启。质量下降时平滑减弱或旁路补偿，不能无限保持旧运动。测残余运动、误估计、退化率、延迟和运算周期。

### A3 防抖与镜头矫正联合重采样

**任务：**消费 A2 的帧级防抖实体与 A1 的视窗，合并到现有几何核。M1 复用仿射入口；M3 接入独立透视除法前端，增加矩阵合法域与齐次分母检查。

**入口：**[几何流水](../fpga/rtl/geometry/geometry_rgb_pipeline.sv)、[仿射递推](../fpga/rtl/geometry/affine_ray_stepper.sv)、[透视前端](../fpga/rtl/geometry/perspective_divide.sv)、[插值](../fpga/rtl/geometry/rgb_bilinear.sv)。A3 是既有几何流水文件的主要修改者，A1/A5 提交端口需求而非同时改同一模块。

**关键实现：**冻结正逆方向、左右乘顺序、像素中心、源/目标内参、定点格式和舍入。先用不对称图案及已知运动证明方向，再测全域精度。矩阵与裁剪实体按帧锁定，数据/mask/tag 同进退；透视不适用时不伪造恒定深度。强缩小需要抗混叠，不能以双线性插值替代预滤波。

**验收：**关闭防抖时保持现有几何结果；分阶段联合逆映射与独立浮点基准比较，保持既有有效域坐标 RMS≤0.05 px、max≤0.25 px 的数值目标，边界 mask 分歧单列。随机背压、缓存失效、算术溢出、迟到响应和参数切换必须覆盖。性能比较使用相同输出质量和运动轨迹。

### A4 历史帧保留 缓存与 DDR 服务

**任务：**为 A5 提供有界历史帧访问，比较保留已有 S1 引用和复制到专用历史槽两种方案。先保留 1 帧，再按预算扩展 2 帧；不得长期锁住现有三个 S1 槽后仍声称采集不受影响。

**入口：**[帧管理器](../fpga/rtl/memory/frame_manager.sv)、[槽管理器](../fpga/rtl/memory/frame_pool_bank.sv)、[原生 DMA](../fpga/rtl/memory/ddr_native_dma.v)、[图块缓存](../fpga/rtl/geometry/rgb_tile_cache.sv)。图块缓存修改由 A4 与 A3 冻结单一写入者。

**关键实现：**历史引用、在途事务、代次与参数实体寿命一致；缓存标签区分历史帧/槽代次/块坐标。补全专用请求按图块局部读取，按期限有界仲裁。比较双回填缓冲/预取与现有单在途回填，不默认返回可以乱序。额外消费者超过现有位图容量时必须显式扩展或统一管理，不能挤占已有消费者身份。

**验收：**新采集/显示/RAW 网络与历史读同时运行，包含快照、取消、断流、源帧被淘汰、迟到响应、epoch 切换及无空槽。退化顺序优先减少补全范围/历史深度，再关闭补全；不能牺牲主视频完整帧却不报告。更新内存布局前确认实物容量并同步跨端方案。

### A5 历史背景补全与来源记录

**任务：**仅对合法当前帧中的几何视场外区域，尝试从前 1～2 帧的真实 S1 取样。优先最近、对齐可信的历史内容；无可信历史则保留无效或交给受限裁边，不保证全画面补齐。

**建议落点：**独立 RTL 可置于 `fpga/rtl/completion/`；参考模型和测试遵循三个开发区规则。A5 消费 A3 的掩码/目标坐标与 A4 的历史服务，不单独创建第二套未经计量的整帧流水。

**关键实现：**历史→当前输出变换由准确源身份和轨迹组合，不直接覆盖上一帧同坐标。检查帧龄、运动残差、遮挡/前景、曝光/WB 差异与参数兼容性；动态区域或场景切换拒绝补全。重叠区融合要限定范围、保留权重，避免低置信度历史污染当前有效像素。首版只从真实 S1 取样，不递归把上次补全结果作为新观测。

**验收：**静态背景已知缺口、前景穿过边缘、历史无覆盖、重复纹理误配、曝光变化、停机后恢复、运动方向反转。分别统计可恢复缺口覆盖率、全缺口覆盖率、误填/重影、历史年龄、当前有效区域是否改变。来源掩码/帧引用随结果保存；不会把算术或 DMA 故障补成成功帧。

### A6 相机 IMU 与滚动快门补偿

**任务：**明确运动对象、IMU 安装位置、平台→相机外参和可观测自由度，再设计短时相机旋转输入。机械 pitch/yaw 不是完整相机姿态，yaw 不是画面内 roll；归一化 XYZ 不是物理平移长度。纯旋转模型也不能精确补偿任意深度场景的平移视差。

**入口：**[姿态选择器](../fpga/rtl/control/pose_frame_selector.sv)、[MCU 主接口](MCU五轴控制与FPGA通信开发交接文档.md)、[MCU 补充](MCU_POSE_V2接口实现补充.md)。当前 STATE 不提供高频原始三轴陀螺流；GET_RAW_IMU 是 PC 单次查询。任何新流、权限、字段或速率先由 A0 冻结，不能复用保留命令或把旧字段改义。

**关键实现：**保留现有舵机优先机械姿态供其原用途，新增防抖观测不能靠简单调权重替代。相机刚性安装、轴向、零偏、滤波延迟和 MCU/FPGA 时钟误差均需校准。短时防抖不要求绝对地磁航向，但必须有可信相机相对旋转。源行曝光时刻与 VSYNC/数据到达的关系需要测量；逐行补偿按源行曝光模型建立，不能直接套 HDMI 输出行时间。

**验收：**单轴正反旋转、时间偏移注入、数据缺失/重复/过期、boot 切换、滤波延迟、快慢运动、滚动快门合成序列及真实对应序列。报告抖动频带、每轴残差和同步误差，不把 200 Hz 发布率等同 200 Hz 新反馈或已验证带宽。未知外参/时间映射时明确退化到视觉或旁路。

### A7 色彩 曝光与抗混叠

**任务：**补齐真实 CCM/白平衡/基础曲线和稳定亮度控制，配合 A3 实现缩小抗混叠。先固定曝光/增益/WB 建立可复现基线，再分别加入受约束 AE、AWB 和曲线选择迟滞。

**入口：**[ISP](../fpga/rtl/isp/raw8_isp.sv)、[CCM](../fpga/rtl/isp/rgb_colour_matrix.sv)、[统计](../fpga/rtl/isp/rgb_frame_statistics.sv)、[150 Hz 交接](OV5640_150Hz_PWM照明防条纹专项优化交接.md)、[摄像头输入契约](../fpga/rtl/input/README.md)。传感器侧与 FPGA 侧色彩控制必须明确职责，RAW 模式下需验证寄存器实际作用，避免重复增益/白平衡。

**关键实现：**150 Hz 光强调制周期约 6.667 ms，固定曝光候选为其整数倍，寄存器值按实测行时间换算并回读。受约束自动曝光不得随意落入条纹显著的非匹配区，也不能通过 VTS 扩行偷偷降低源帧率。6.667/13.333/20 ms 等档位分别比较条纹、噪声、饱和与运动模糊；防抖不能恢复已经曝光模糊的细节。

**验收：**占空比/频率漂移/亮度变化、色卡、中性灰、细线/棋盘格、运动场景；记录每帧曝光/WB/曲线实体。自动参数变化时 A2/A5 接收质量或兼容性状态，避免把亮度变化解释成运动或直接融合不同亮度历史。验收区分光学闪烁和几何抖动。

## 6. 性能 存储与延迟预算

| 项目 | 计算值或既有局部结果 | 工程含义 |
| --- | --- | --- |
| 1080p30 | 62.208 Mpixel/s；33.333 ms/frame | 输入、处理、显示新帧、RAW 网络完整帧分别验收 |
| RGB888 一帧有效数据 | 6,220,800 B | 每额外整帧读取在 30 fps 下为 186.624 MB/s 有效读量 |
| S1 stride=6144 的地址跨度 | 6,635,520 B/frame | 布局跨度不是必然 DMA 传输量；现有 RGB 槽为 8 MiB |
| 两份新增 8 MiB 历史槽示例 | 16 MiB，元数据/掩码另算 | 只是布局候选，不证明实物容量足够，也不自动更改 76 MiB 方案 |
| 1080p 的 1 bit/2 bit 图 | 259,200 / 518,400 B | 不含行对齐、置信度、来源索引或 DMA 流量 |
| 480×270 灰度候选 | 129,600 B/frame | 估计支路预算，不改变主视频分辨率 |
| 当前几何条件模型 | 27.577667 ms@150 MHz | 不代表还剩固定 5.76 ms 可供任意新增模块使用 |

实际额外历史读量按有效请求、总线字节和回填放大系数统计。若采用复制历史槽，另计复制读取和写入；若保留原 S1，另证槽周转不会阻塞生产。禁止只统计缺口像素字节而漏掉 DDR 对齐、重复读取、双线性邻域和缓存 miss。

逐帧延迟需拆分采集、运动估计、几何、补全、队列及显示等待。M1 优先因果平滑，不主动等待未来帧；若候选需要 L 帧前瞻，30 fps 下仅前瞻就增加约 L×33.333 ms，必须明确比较。完整 S1 到达后才启动的几何和估计不能被计成零延迟。

为保证吞吐可以增加流水、双缓冲、并行采样和 RAM 副本；新增模块后重新检查整机资源/时序，不能把各独立夹具资源简单相加作为最终报告。多帧访问导致拥塞时，先有界缩减补全功能，保持原始证据与主视频服务。

## 7. 验收方法与测试矩阵

所有阈值区分既有硬目标和待冻结候选。1080p30、不压缩 S0、身份一致及错误显式报告沿用主方案；防抖/补全质量没有现成实测基线，A0 必须在相同视场与裁剪约束下冻结目标，不能事后选最有利片段。

| 指标 | 计算或记录方法 | 交付要求 |
| --- | --- | --- |
| 完整帧率 | 真实采集/处理/成功输出的新帧/完整网络帧分别计数，重复帧单列 | 按主方案验收真实 30 fps；过载和丢帧不得隐藏 |
| 数值精度 | 联合映射对独立浮点模型，全支持域扫描；mask 分歧单列 | 有效域 RMS≤0.05 px、max≤0.25 px；不等同光学重投影精度 |
| 残余抖动 | 静态背景点相对目标轨迹的输出像素残差；平移和角度分别报告 | 可将“规定抖动频带 RMS 较关闭模式降低至少 50%”作为首轮候选，需先冻结频带、视场、测试幅度，非既有硬指标 |
| 视场与裁剪 | 保留宽高/面积、缩放上限、逐帧变化率、补偿饱和比例 | 与抖动指标同时报告，不能无限放大换稳定 |
| 补全覆盖 | 全缺口填充比例与有历史真值可恢复区域的成功比例分开 | 不预设 100%；错误补全不能计为成功 |
| 补全质量 | 合成/离线真值误差、动态前景误填、重影、边缘闪烁、历史帧龄 | 当前帧与历史区域分开统计；真实无真值场景不伪造 PSNR |
| 延迟与服务 | 平均/p95/p99/最大端到端延迟，队列峰值、截止违约、DDR 总线字节 | 包含所有支路；模型和实测分开；记录真实时间基准 |
| 来源完整性 | 帧/槽代次/参数/运动实体/补全掩码与引用逐项核对 | 错源、过期引用、未登记历史来源为失败 |
| 时序与资源 | 相同功能/时钟下 post-PnR 多 corner setup/hold、CDC/外部约束与资源 | 不能扩大例外或降低约束后宣称性能提升 |

最低测试集：

1. 全功能关闭、identity 和既有几何回归，确认未引入行为改变。
2. 独立生成器产生已知运动、镜头畸变和缺失真值，不用 DUT 输出生成唯一黄金结果。
3. 平移/正负旋转/组合运动/慢速转向叠加抖动，覆盖整个承诺参数域。
4. 低纹理、重复纹理、大运动前景、遮挡、场景切换和无历史覆盖。
5. 曝光/WB 跳变、150 Hz PWM 不同档位、运动模糊与低照度噪声。
6. RAW 网络、HDMI、快照与历史 DMA 混合压力；随机和有界最坏停顿，检查截止与整帧失败。
7. PCLK 停止、复位/epoch/boot/配置切换、历史淘汰、迟到响应、取消排空及状态恢复。
8. 硬件获准后采集原始 `.raw/.rgb` 和元数据，记录来源、实际时间、曝光及位流哈希；PNG 仅用于派生展示。
