# FPGA通信子系统与PRAW发送实现V1

日期：2026-09-21。范围：FPGA侧RTL、离线仿真及原生PDS工程，不执行烧录。

实际交付与验证记录见[离线实现报告](../fpga/reports/comms_offline_20260921.md)：完整协议回归通过，PDS生成/编译/综合完成，但hold估计违例与板级约束尚未闭合，不标为可烧录版本。

## 1. 与现有工程的关系

当前已验证的摄像头HDMI工程仍为RGB565/1280×720；其启动表、采样、DDR与HDMI不在本次替换范围。通信子系统采用独立工程，不能把RGB565字节冒充RAW8。网络RAW实时入口必须来自未来RAW8模式的已完成S0帧及读DMA；RGB888只按现有PRAW的S1/S2/S3快照类型发送。新增协议并不声明ISP、RAW模式、DDR读DMA、快照冻结已经完成。

MCU链路见[FPGA-MCU协议](FPGA_MCU通信协议V1.md)，是独立UART的环境事件与状态通道，不替代现有MCU电机文本命令端口，不把MCU时戳当作FPGA时间，不控制电机运动。MCU侧固件适配与引脚/电平冻结另行实施。

## 2. 网络线格式

保留[跨端方案](OV5640_RAW8千兆网与HDMI双路回传方案.md)§6及已有host/src/pango_video/protocol.py：PRAW V1，64字节小端头，固定1400字节非尾块，CRC32/ISO-HDLC覆盖CRC字段清零的头及真实载荷。RAW_LIVE=1/RAW8/Bayer1..4；SNAP_S1=2或SNAP_RESULT=3/RGB888/Bayer0。紧凑行跨度，不发送DDR行尾填充。

1920×1080 RAW8为2073600字节、1482包，尾块200字节；帧号/代次/参数版本/描述符必须来自产生此帧的真实源状态，不能在每包发送时读活动全局计数。网络重连不自行递增源epoch。

Ethernet II / IPv4无选项 / UDP单播，IP总长最大1492B，无分片，UDP载荷最大1464B。网络头大端，PRAW头小端。IPv4头校验、以太网FCS分别生成；IPv4 UDP checksum=0表示未生成UDP校验，应用CRC仍执行。依据[RFC 768](https://www.rfc-editor.org/rfc/rfc768)与[RFC 791](https://www.rfc-editor.org/rfc/rfc791)。

V1 RTL端采用静态目的MAC/IP/端口配置，不实现ARP/DHCP/ICMP或自动邻居发现，不宣称可即插即用。MAC/IP/端口在帧开始锁存；50000/50001仅沿用host模板默认目的/源端口，不是已分配现场地址。实板连接前须确认独立有线链路与主机接口配置，不自动修改PC系统网络设置。

## 3. FPGA数据接口与所有权

- 网络核心时钟125MHz；帧描述符用frame_start/frame_ready握手一次锁存。只有完整帧才能请求发送。
- pixel_valid/ready/data[7:0]/last为读DMA输出；背压时数据和last保持，允许DDR读取暂停。不可把不能停的DVP线直接接该接口。
- 网络队列满时，帧池不阻塞摄像头和HDMI；上层按整帧拒绝/丢弃并统计。完成和错误释放槽的时机由帧池适配器负责，当前接口不自行读写DDR。
- 输入last必须精确位于frame_bytes-1；提前、缺失、超时均丢弃未发布分块。已在链路上的早期包不可撤销，host按不完整帧超时丢弃，禁止补零出图。
- 双包缓存交替构造PRAW与向MAC交付；MAC同样双缓冲，发送开始后GMII每周期一个字节且不可暂停。发完保持至少12字节周期IFG。
- frame_done只表示最后应用包已交付MAC队列，不表示主机收到；MAC done只表示单个以太帧发完。没有PC应用ACK，不声称可靠送达。

## 4. 时钟、电气与安全边界

UART引脚通过同步器进入通信时钟域；网络入口必须处于同域，其他帧池时钟必须使用已验证异步FIFO/描述符握手适配，禁止多位总线逐位同步。

RGMII TX使用PDS原生ODDR低/高半字节输出及延迟90度发送时钟输入；最终PLL、PHY内部TX延迟选择、板级走线与外部时序必须联合核对，避免重复延迟。本次不改已固化镜像，不设置未知MCU引脚，不把逻辑模型仿真当成PHY实际链路。

## 5. 离线验收

MCU：串口脚级正确/坏CRC/错误版本/超长/截断超时、重复事件、会话失配、复位恢复。网络：短包/边界/多包完整1080p、CRC/端序/尾包、非法描述符、随机或确定性背压、源超时、复位；RTL产生的UDP负载交由现有host解码器逐包校验并重组比较全部字节。GMII独立检查前导码、SFD、IP校验、UDP长度、padding、FCS与IFG。吞吐只报告仿真周期预算，不报告实际千兆吞吐。

源码、脚本和仿真报告归fpga，跨端设计归output。MCU/host既有代码不改变线格式；本轮不执行JTAG、Flash、实板网络发送或采集。本轮云端备份只推FPGA专属分支，不推实测视频。
