# 项目设计文档

当前方案：PG2L100H（盘古100Kmini），官方建议双目OV5640 DVP模组启用一路；稳定1080p30必须达到，更换真实60fps输入源后进一步实现1080p60。

- [详细设计方案](./PG2L100H_1080p畸变矫正详细设计方案.md)：硬件、RAW输入与ISP、定点算法、帧缓存、DDR/cache、HDMI扩展、IMU、验证。
- [两个月开发规划表](./两个月开发规划表.md)：8周＋交付缓冲，日期、工作角色、交付检查点与失败处理。
- [历史PGL50H方案](./单路OV5640_DVP_盘古50K畸变矫正系统设计方案.md)：仅供追溯，平台和输入假设已由当前方案替代。

当前技术决策：OV5640的1080p30优先验证RAW DVP，不能沿用8位DVP RGB565；1080p60需要其他视频源。100Kmini配套手册列出32位DDR与MS7200输入，但DDR容量和HDMI输出实现需按实际修订确认。详细依据见设计方案。
