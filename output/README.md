# 项目规划文档

本目录仅保存需求、方案、开发计划和验收设计。实现代码、工程、构建结果与实测报告直接写入 [fpga/](../fpga/README.md)、[mcu/](../mcu/README.md) 或 [host/](../host/README.md)，不放在 output/。

当前方案（2026-09-06）：PG2L100H（盘古100Kmini），官方建议双目OV5640 DVP模组启用一路；RAW8原图S0经板载千兆网回传，FPGA完成ISP和矫正后的RGB888结果经唯一HDMI输出回采。真实1080p30必须达到；60fps需更换真实输入源并重新设计或升级原图回传。

- [RAW8 千兆网与 HDMI 双路回传方案](./OV5640_RAW8千兆网与HDMI双路回传方案.md)：当前架构、76MiB帧池、网络V1、同源证据、标定解析、能效与独立演示。
- [详细设计方案](./PG2L100H_1080p畸变矫正详细设计方案.md)：硬件、RAW输入与ISP、定点算法、帧缓存、DDR/cache、HDMI扩展、IMU、验证。
- [可控光照箱与上位机测评详细实施方案](./可控光照箱与上位机测评详细实施方案.md)：箱体与MCU控制、串口姿态、同帧快照、测评接口、质量与性能测试、自动报告和现场演示。
- [光照黑箱详细设计](./光照黑箱详细设计方案.md)：箱体尺寸与视场包络、四路灯位/安装剖面、图卡匣定位与更换、光照校准和装配验收，附4张SVG/PNG示意图。
- [F407五自由度运动与光照系统](./STM32F407ZGT6_三轴龙门架与二维无刷云台黑箱测试系统设计方案.md)：三轴龙门架、Roll/Pitch云台、四路恒流灯及控制保护。
- [上位机专项规划](./host/README.md)：输入输出与数据约定、硬件连接与通信、算法处理与测评、开发流程和规划。
- [两个月开发规划表](./两个月开发规划表.md)：8周＋交付缓冲，日期、工作角色、交付检查点与失败处理。
- [历史PGL50H方案](./单路OV5640_DVP_盘古50K畸变矫正系统设计方案.md)：仅供追溯，平台和输入假设已由当前方案替代。

当前技术决策：OV5640的1080p30先验证RAW8 DVP，不能沿用8位DVP RGB565。PC只做S0基础彩色预览，正式测评采用板端S1与同源S2/S3未压缩快照；连续HDMI回采的源帧关联另行验证。100Kmini有32位DDR、RTL8211F千兆接口、MS7200输入及FPGA直出TMDS；DDR容量与实际输出能力仍需实物确认。以上均为规划，未完成网络、采集或硬件验证。
