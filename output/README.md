2026-10-20 最新范围：[FPGA 仿射与图像增强及剩余功能实施交接](./FPGA仿射与图像增强及剩余功能实施交接.md)。以仿射替代完整透视，精简为前置亮度增强并开放颜色参数；完成自动 Gamma、LUT 上传、MCU 受限仿射跟随、视觉防抖、历史补全、自动裁边和相机亮度控制。删除相机 IMU／滚动快门、板载功能按键、60fps／第二源／双目扩展；同源快照删除继续有效。此为待实施设计，代码完成情况须以新验证记录为准。

2026-10-20 已确认删除板端 S1／结果同源快照功能及其对应代码，保留 S0 千兆网连续回传、处理结果 HDMI 输出和增强／几何参数控制。执行范围、协议撤销、帧池调整与测评边界见 [FPGA 同源快照功能删除开发交接](./FPGA同源快照功能删除开发交接.md)。当前活动实现已删除快照链路；下列旧方案中同源快照必备要求以本次决定为准，实施时同步更新。

本目录仅保存需求、方案、开发计划和验收设计。实现代码、工程、构建结果与实测报告直接写入 [fpga/](../fpga/README.md)、[mcu/](../mcu/README.md) 或 [host/](../host/README.md)，不放在 output/。

当前技术决策：OV5640的1080p30先验证RAW8 DVP，不能沿用8位DVP RGB565。PC只做S0基础彩色预览，同源S1/结果快照已撤销，严格实板像素配对不再由现有网络提供；连续HDMI回采的源帧关联另行验证。100Kmini有32位DDR、RTL8211F千兆接口、MS7200输入及FPGA直出TMDS；DDR容量与实际输出能力仍需实物确认。以上均为规划，未完成网络、采集或硬件验证。
