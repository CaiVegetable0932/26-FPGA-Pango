# 布线结构优化候选验证（2026-10-24）

第一批结构候选已实现并通过软件验证；尚未验证物理收益，未选为生产版本、未生成位流。遵照用户“保留旧 L 布线，先完成 RTL 与软件仿真”的选择，本次不启动 PDS，不修改旧任务冻结源码、锁或 live 门禁。以下所有新结果均为仿真，不能替代真实 1080p30、时序或板级验收。

## 候选与改动

独立候选：`fpga/build/route_structure_20261024/candidate_20261024_195102_683270/`。

基线为 `fpga/build/full_integration_20261013/board_postsyn_20261023_221908_913042/source/` 的 L 源码，复制 321 个文件，仅改动以下三个 RTL。`baseline_sources.json`、`sources.json` 保存全部 SHA256；`baseline/` 保留三份原件，`patches/` 保存逐文件补丁，`candidate.json` 记录作用范围。

| 文件 | 实现 | 预期作用及代价 |
|---|---|---|
| `rtl/stabilization/motion_config_bank.sv` | 将接收使能与 pose 发布使能显式分开，普通同步使能设置 `syn_maxfan=64`；pose 内容与身份同沿发布 | 请求综合复制高扇出控制逻辑；实际复制数量、扇出和 LUT 未验证。没有增加配置生效延迟 |
| `rtl/memory/ddr_native_dma.v` | 新增 SELECT 预留阶段，锁存 owner 后再提交原生地址；提交前复查取消、资格与控制器就绪；只在提交时计入配额和轮询游标 | 拆开资格/优先级到发起控制的组合路径。每次正常仲裁增加一个周期；不能称为吞吐优化 |
| `rtl/memory/geometry_tile_refill.sv` | 在行窗口选择与下游 CDC FIFO 之间增加单级弹性缓冲，锁存 96 位像素及 last/error/bus_bytes；有效位复位，载荷寄存器不复位 | 隔离输出组合路径；持续发送仍可一周期一个 quad。末拍受阻时保持任务占有，取消不改写已经发布的拍 |

本批没有实现复位树分区，也未修改 DDR PHY/IP、时钟、外部时序或帧池协议。异步复位不能靠普通网的 `syn_maxfan` 达到同样效果。

## 性能取舍与降频判断

帧预算按 DDR 域 125 MHz、30 fps 检查，不能只检查最后一帧。

| 项目 | 基线 | 候选 |
|---|---:|---:|
| 最大几何周期 | 3,972,392 | 4,062,917 |
| 最大几何时间 | 31.779136 ms | 32.503336 ms |
| 距 33.333333 ms 的余量 | 1.554197 ms | 0.829997 ms |

候选三帧周期分别为 4,011,297 / 4,062,917 / 4,032,136；最大值增加约 2.28%。基线全帧记录 `verilator_20261023_215122_863087` 的 RTL 已按 L manifest 核对，仿真夹具与本次相同。基线和候选仿真墙钟耗时受同时运行的任务影响，不用于比较硬件速度。

独立 DMA 混合负载三个种子的耗时由 3,949 / 3,977 / 4,023 周期增至 4,116 / 4,147 / 4,191，约增加 4.2%。因此需要用后续物理收益决定是否保留 SELECT，不能仅凭软件正确就选定该方案。

本批保持处理域 150 MHz、DDR 域 125 MHz。按当前观测周期机械折算，30 fps 需要至少 121.88751 MHz 的 DDR 频率，但该数值不是可用的降频配置，也没有覆盖真实 DDR 等待、传感器/显示并行压力及其他处理时钟比变化。剩余余量有限，不据此下调时钟。放宽目标周期不会减少跨区域连接数量，也不能作为广域拥塞已解决的证据。

## 后续物理比较顺序

1. 旧 L 任务结束且原监督器释放 native 槽位后，再为此候选单独启动综合与 MAP。不要复用或修改旧运行中的输入。
2. 先检查普通网复制是否实际生效，再检查 LUT、FF、RAM/DSP 与热点网络的扇出；L 的 MAP 为 46,152 LUT，严格 `<46,620` 门禁只剩 467 LUT 余量。候选未取得资源报告，当前不宣称满足该门禁。
3. 利用三份独立补丁分别比较“仅配置使能”“仅 DMA”“仅回填”及组合，确定收益来源；面积或吞吐代价过大的改动撤回。后续可针对帧池 bank 局部化和复位分区继续做独立候选，不同时引入大范围接口变化。
4. 资源通过后再做有界布局/布线，比较未布通子网走势、分区拥塞和耗时。最终仍须未布通为零、完整 routed DB、min/max STA、外部接口时序及位流门禁，不以首轮未布通下降替代完成。

候选的 `pds_run=false`、`physical_signed_off=false`、`production_selected=false`、`bitstream_generation_allowed=false`、`hardware_tested=false`。副本中的历史 readiness 文件只是基线的一部分，不授权启动或发布。生产 RTL 与 live 门禁未由本次修改。
