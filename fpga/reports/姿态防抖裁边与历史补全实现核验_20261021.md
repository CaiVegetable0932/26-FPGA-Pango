# 姿态、防抖、裁边与一帧历史补全实现核验

日期：2026-10-21。本文只记录本次源码和仿真结果，不是实物、PDS MAP/PnR、1080p30 或光学标定通过报告。

## 实际接入

- `video_memory_core` 在源采集边界按槽保留 motion 实体和版本。`source_motion_controller` 的工作结果必须匹配 epoch/frame_id；几何作业最多等待 65535 个 DDR 周期，超时用该源冻结的手动矩阵并计数，DVP 不等待估计器。最终六参数通过原有作业 CDC 进入真正几何、DDR、HDMI 路径。
- `pose_affine_model` 使用机械 pitch/yaw mdeg，先转换到 Q30 弧度，再计算 `A_ref + J_pitch*delta_pitch + J_yaw*delta_yaw`，六项使用 S(32,26)。转换常数为 `round(pi/180000*2^46)=1228166276`，局部差角额外限制 ±90000 mdeg；64/66 位中间乘加在整组返回前检查溢出。超域、时间误差、MCU 配置版本或样本无效均回到本源手动矩阵。没有 roll 或 XYZ 物理长度输入。
- MCU 使用既有 `mcu_readonly_client` 与 `pose_frame_selector`，独立字节链。new_session、配置实体接收/批准、reopen_required、event/ready 显式导出，不自动丢弃配置再假定已批准。板级没有已验收独立 MCU 引脚/时间边界时保持 disabled/unapproved，不能把内部接入写成实物跟随已完成。
- S1 低通使用 64×36 两页缩小图；1080p 每个采样为 30×30 区域平均。三块 8×8 区域进行 ±1..4 缩小像素 SAD 搜索，估计平移以及左右区域差异形成的小旋转/尺度，检查纹理、次优代价差、最大 SAD 和中心残差。采集抢占估计时丢弃该估计，原视频不暂停。一次 radius=4 搜索约 31100 周期，实际 cycles 为模块计数。
- 因果轨迹平滑/补偿限幅在本地运行。`affine_dynamic_compose` 按 `S*M*V` 顺序串行运算，Q16 像素视窗平移不误塞入 Q26/i32，33 周期恢复除法计算 zoom 倒数，没有逐像素齐次除法或第二次整帧插值。
- 裁边提供保留视场、固定 zoom、受限动态需求；支持步长、迟滞、最大 zoom 和矩形保留视场比例下限。动态 crop 对非零 lens 系数明确旁路并报告状态 7。固定 crop 仍执行真正 lens 与四邻域有效掩码；不能保证的区域保持 invalid 并计数。
- `HISTORY=3` 是独立 SRC 消费者，最多一个旧 S1 引用。不会恢复 SNAP 银行或外部快照命令。调度器保持旧引用直到整个当前几何作业/读 DMA 排空，再领取/校验新真实 S1；不足时跳过/释放历史，不能卡住 DVP。
- 当前合法坐标优先。仅 `map_ok=1` 且当前坐标域外时允许历史；历史仍执行同一 RGB 查表、插值和当前输出曲线。cache tag 加一位 current/history 域；DDR tile mailbox 同步该位，实际 SRC 请求选择对应 base/slot/generation，owner=4 对应 HISTORY 引用。DMA、算术溢出和坏采集仍使整个结果失败。
- 历史采用相邻源帧的平移注册，仅限源边界外 32 像素，要求零估计旋转/尺度、同 epoch、相邻 frame、匹配 ISP/相机/几何实体、满足亮度差/置信度/注册版本。注册版本对应源绑定 STABILIZATION_CONFIG 版本。配置允许 max_age=1..255，但当前注册仅证明相邻帧，因此不会将任意更老图像当作已配准。
- A5 action3 视觉参考重置/action4 历史清空由 `frame_runtime_actions` 排队，在下一实际 capture boundary 执行；同最近成功 sequence/action 重试不再执行、同 sequence 不同 action 冲突、另一个 pending 时 busy。清除只请求 scheduler 排空，不提前丢掉在途 DMA 的旧 S1 所有权。kind11 body88 为 pending 位，89 最近已执行 action，96/104/112 分别为独立动作 epoch/frame/sequence，不能与最近完成作业身份混同。
- kind 11 `MOTION_FRAME` 只读：整个完成记录在 `geo_done` 原子发布，包括实际六系数、同源身份、pose/visual 状态、历史源、current/history/invalid 覆盖计数及六类实体版本。它证明的是板端处理作业，不证明采集卡 HDMI 回调来源。

## 未完成或未证明的范围

1. C3 缺实测局部模型、真实装配/焦距/有效角域误差、独立 UART 电平/引脚、配置归档批准和时间映射误差验收。上传标定 ID 非零不等于实测通过。
2. C4 当前可证明的 pixel→ray 转换仅覆盖 lens 系数为零、fx=fy、主点居中、未旋转/缩放的规范基础归一化矩阵。其他域报告状态 4 并旁路；强畸变稀疏校准变换尚未实现。MCU 跟随开启时未建立有意运动残差模型，视觉补偿旁路，不能宣称两者组合完成。
3. 64×36 整像素匹配的最小位移步长在 1080p 为 30 像素；没有亚像素 SAD 拟合/全分辨率精配。已证明合成大位移与低分辨率区域模型，尚未证明真实小抖动、前景遮挡、曝光变化下的残余运动指标。
4. C6 的动态需求是受限无畸变域的保守需求与变化率控制，尚未提供每个任意 lens/矩阵组合的自动全域有效裁边证明。`verify_viewport` 离线遍历所有输出像素，但量化 margin 不是完整硬件误差界证书。全像素 RTL mask/invalid 计数不会伪称有效。
5. C5 已有真实一帧 S1 DDR 采样和生命周期，但当前只支持上述有界平移注册，未实现一般旋转/尺度历史注册或逐像素前景/遮挡分类；三块一致性、亮度阈值是拒绝条件，不是遮挡保证。动态实景误填/重影仍需测量。
6. 新 DDR/处理域包含 history domain 和计数 bundled-data 变化，必须以本版源码完成新约束审查、SYN/MAP/PnR、APM/DRM/LUT 与吞吐统计，不能沿用旧成绩。没有占用或更改其他任务的 `native_phase.lock`。

## 视窗硬上下界与缓变冲突

只读复核发现旧逻辑先夹到新 min/max，再按上一源的 zoom 做迟滞/步长限制，用户收紧 max 或提高 min 时可能重新逃出硬界。修复仅在缓变后再次夹到当前源冻结的 min/max；新硬约束优先于过渡速度，不扩展畸变可用域。`tb_viewport_bounds` 通过真实实体提交、采集边界、source_start、job/controller 和 composer 接口运行三帧 fixed2→dynamic min=max1→dynamic min=max2，未 force 内部结果。

当前 `verilator_20261021_193236_355101` PASS；同 fixture 对旧 board192958 源的 `verilator_20261021_193246_925170` 在第二帧精确 FAIL：缩小 max 后 a00=1056832，期望2097152。二者均保留冻结输入及结果。该修复之后完成一轮 source 身份/配置冻结、轨迹符号/溢出、历史域/故障处理、动作/引用生命周期只读复核，未发现其他确定缺陷；这不替代整板时序或实物验收。
