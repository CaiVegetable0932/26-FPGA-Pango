# 1080p RAW8 双路：核心实现及离线验证

日期：2026-09-22；分支 `codex/fpga-raw8-dual-output`；基于 main 的 `331f6078156aba7adabdf8422752d9847ee3a3e8`。

**当前状态：核心模块与离线验证完成，整板集成未完成，不是可烧录版本。没有执行 JTAG/Flash，也没有改变板卡正在运行的合成以太网镜像。**

## 已实现

`rtl/raw8_dual/` 新增独立实现，原 720p 摄像头恢复链路和合成以太网 top 未改动。

| 模块 | 用途 |
|---|---|
| ov5640_raw8_profile / startup | 保留 MINI 模拟初始化，待机写入 1080p RAW 配置，61 项回读、ID/运行状态检查，失败关闭采集 |
| raw8_capture | 一字节一像素，低地址字节先行打包 256-bit，完整行/帧检查、FIFO 溢出拒帧、输入帧号 |
| raw8_frame_pool | 三个 RAW 槽、HDMI/网络独立读锁、保留最新帧、无空槽拒收、提交栅栏门禁 |
| raw8_read_scheduler | 每行 60 个有效 DDR word，跳过 4 个 padding word，16+16+16+12 burst |
| raw8_unpack / network_output | 背压下无损拆字节，复用 PRAW/IPv4/UDP/MAC，传播报文与 MAC 故障；无测试源选择器 |
| raw8_hdmi_timing | 1080p30 栅格，RAW 灰阶，欠载后整帧剩余区置黑并计数 |
| raw8_native_queue | 原生异步 FIFO 的非 showahead 读适配、背压保持，256/288-bit 两种配置 |

host 默认增加“RAW 灰阶”：1920×1080 不平均 Bayer 小块、不去马赛克，每个 RAW 字节复制到 RGB；原始数据不变。软件预览不等于 S1。原有测评及 HDMI 身份门禁保留。

## 实际验证结果

- [完整 RTL 回归](../build/raw8_dual_sim_20260922_205127_531/result.json)：1920×1080 打包逐字节正确；短行/长行/多余行/堵塞拒帧；摄像头正常、错误 ID、NACK、回读错误四例通过；帧槽与缺写栅栏测试通过；4320 次 DDR 读 burst 共 64800 word 地址/长度正确。
- 同一份 DVP **仿真激励** 经 capture 写入理想 DDR 模型，同时供 HDMI 与网口读取：2,073,600 个 HDMI 有效像素全部一致；总周期 2200×1125、HS 高电平 49500 周期、VS 高电平 11000 周期、欠载 0。
- 网口输出 1482 包，2,269,248 个 125MHz 仿真时钟周期（18.153984ms）。实际 host 解码器验证 FCS、IPv4 校验、PRAW CRC、字段并重组整帧，所有 RAW 字节一致。这个数是理想存储条件下的模块结果，**不是整机吞吐或摄像头 30fps 实测**。
- 测试 RAW SHA256：`d0195d3c68e3c022e4c9d4c81922e327f36b5bb37d303e500abffcadf4b23a7b`。该值来自测试台，不能作为真实相机来源证据。
- [原生 FIFO 回归](../build/raw8_native_sim_20260922_205155_956/)：PDS 原生模型，256/288-bit 各 4096 word，异频时钟、填满、背压、序号绕 FIFO 地址回环均通过。模型包含零次重复/未选分支越界警告，完整日志保留，未修改生成 HDL，未据此作整板 CDC/STA 签核。
- [原生 IP 生成](../build/raw8_native_ip_20260922_204406/)：PDS 2022.2-SP6.4，两个 DRM FIFO 均为 0 error / 0 warning；HDL、IDF、模板与依赖在 fpga/ip 保留。
- [PDS 网络端点编译/综合](../build/raw8_network_core/native_20260922_205024_356/result.json)完成。工程由 `tcl2prj` 原生生成并重开；它只包含网络端点，不是 MINI 顶层。只有内部 125MHz 时钟约束，组件外部端口未作板级 I/O 约束，相关警告保留，不作时序通过结论。
- [host 像素测试](../../host/reports/webui-frontend-tests.json)：10 项通过，包含 1080p 全像素 RAW 灰阶及输入不变性；`test_webui.py` 19 项通过。未在本轮打开真实硬件预览。

## 尚未完成 / 不得混淆

核心并行输出测试使用理想 DDR 存储；原生 FIFO 是另一个模块测试，二者不能合并声称整板 DDR/CDC 已通过。尚缺板级 top、DDR capture 写排空/提交、读仲裁及锁交接、RAW 控制面描述符/epoch 准入、HDMI 欠载后的 DMA 重启、物理输入时序及原生整板 PNR/STA。

因此没有新位流、没有烧录、没有真实摄像头 1080p30/双路完整帧率或来源证明。后续步骤见 [实施增量](../../output/FPGA1080pRAW8双路实施增量.md)。不合并 main，不上传实测视频。
