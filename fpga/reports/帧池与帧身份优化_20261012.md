# 帧池与帧身份优化交付记录

2026-10-12；专项 03。当前交付为正式帧管理控制 RTL、同源快照生命周期及可复现局部回归。真实 DDR 数据搬运、板级接入、整机吞吐、资源用量和时序收敛仍待验证。

## 改动与实现范围

新增 `fpga/rtl/memory/frame_manager_pkg.sv`、`frame_manager_layout.vh`、`frame_pool_bank.sv`、`frame_manager.sv`、`frame_snapshot_pair.sv`，以及该目录 README。新增三个专项 TB、字段布局生成脚本、仿真入口和独立 PDS benchmark 工程。实现与产物全部位于 FPGA 开发区。

主要行为：

- 固定五池 11 槽、76 MiB byte 地址布局；RAW 三槽各 4 MiB，保留两个独立 8 MiB 快照槽。拒绝超尺寸、错误格式/stride 分配。
- 每池独立推进；四消费者 pending/owned 位与精确槽代次；按分配顺序获取完整源帧，早分配帧未 READY 时不越过它。
- READY 要求合法性、元数据 seal 与全部生产者写 drain；release/cancel 保留全部在途读写保护。显示只在 display_boundary 获取新槽。
- 每次分配更新 generation，每次事务 token 复用更新 ticket；错代次 seal、重复 release、重复/迟到 complete 拒绝。issue/complete 可同周期执行，错误/cancel 阻止同周期新读取。
- u64 epoch/frame_id 与实际阶段版本、不可变实体引用、时间戳、尺寸/格式保持原子关联。PC 会话不参与源身份重标。
- 同源 S1 与选定结果校验后复制到两个专用槽；复制全部排空后释放持续帧槽；两图独立慢速导出；第一图释放后仍允许第二图领取。超时、复制取消及导出错误都有回收路径。

接口完整定义及 02/04/05/06/07 接入要求见 [memory README](../rtl/memory/README.md)。其中 drain/cancel 是需要 04 原生适配证明的内部契约，本轮没有完成跨分区硬件签核。快照请求需要提前登记确切源槽/代次；参数实体内容及回读数据库仍由集成方提供。

两个板级顶层、现有诊断 RTL、共享工程/IP/板级约束、网络头及跨端权威布局均未修改。既有工作区改动未回退，未更改 Git 忽略规则，未执行下载、Flash、eFuse 或其他硬件操作。

## 现有诊断机制审计

审计当前工作区 `mini_frame_pool.v`、`vendor/Top.v`、`frame_fifo_write.v`、`frame_fifo_read.v`，并执行原诊断帧池 TB。

| 现有机制 | 可复用基础 | 正式系统缺口/处理 |
| --- | --- | --- |
| 四槽候选排除 latest/显示/写槽 | 在用槽保护思路 | 新控制器使用消费者位与全部在途事务保护，不使用诊断 latest 替代顺序处理 |
| wstate=0 的 DMA finish 发布 latest | 写后发布方向 | 原 finish 不含输入合法性、元数据及可见性证明；正式 seal 与 drain 分离 |
| 四阶段请求/ACK | 单 bit 请求 CDC 思路 | 元数据/代次必须整体握手/FIFO；正式模块全部在 DDR 域，不自动完成 CDC |
| DMA 新请求在 burst end 进入 ACK | 旧 burst 完结后换槽 | ACK 尚不能替代正式所有响应 drain/cancel 契约，需 04 原生核验 |
| Top 57,600 个 32 B 字、地址间隔 65,536 字 | 720p RGB565 诊断配置 | 四个 2 MiB 槽；不用于正式 RAW 2,211,840 B 带 stride 帧 |
| completed/abandoned 计数 | 局部事件观测 | 没有严格源身份、参数实体、消费重复/跳帧和完整网络帧验收证明 |

原模块继续用于诊断，不能据本轮 TB 宣称真实输入帧合法、无撕裂或 HDMI 历史帧来源已验证。

描述符宽 616 bit，命令 1046 bit，回应 2856 bit；类型布局由脚本生成同宽偏移。11 槽描述符逻辑存储共 6776 bit，核心显式状态账本约 11750 bit，串行 benchmark 外壳另有 1046+2856 bit。这些是源码结构计数，不是综合 FF/DRM/LUT 用量。

先用向量描述符存储规避安装版 ADS 结构体数组展开内部错误，再拆为每槽独立寄存器块，最终把综合核心结构体字段访问展开为同宽位向量；上层 typed 描述符和行为通过完整回归保持一致。未用减少正式槽数或取消快照/事务保护换资源。

## PDS 检查与未通过范围

使用安装版 PDS 2022.2-SP6.4 build146967，独立目标 PG2L100H、FBG676、-6，`frame_manager_bench` 仅保留控制状态及串行观测，不是可下载板级顶层，未实例化快照控制器。

原始安装资料只读查阅：`Simulation_User_Guide.pdf` §1/§2，`ADS_Language_Support_Reference_Manual.pdf` §2.1/§2.2/§2.5，以及 `Pango_Design_Suite_User_Guide.pdf` 综合语言配置与命令行章节；结合 MINI 参考说明及目标工程确认器件/封装。安装版 `help compile` 确认 `-system_verilog`；未按其他平台语法推断。

第一次未启用 SystemVerilog的诊断尝试被工具拒绝；修正语言选项后通过解析。结构体数组版本触发 ADS 内部错误；向量存储及后续候选通过解析/展开/rtl-prep，随后长期停留于 DFF-inference。前两次长推断已核验精确父子进程身份后结束，仅结束本专项进程。

最终位向量候选使用有界综合入口。长推断日志保存为 `pds/vector_core_long_inference.log`；最终另以 30 秒预算核验入口的超时记录与自有进程清理，实际等待约 31.14 秒，passed=false、timed_out=true、fresh_report=false，结果保存于 [pds/synthesize.result.json](../build/frame_manager/pds/synthesize.result.json)。原始标准输出/错误位于同目录 `synthesize.console.log/synthesize.stderr.log`。当前交付未取得综合完成与资源/时序报告。

原向量存储候选与中断日志保留于 `fpga/build/frame_manager/candidates/vector_storage/`；每槽候选长期推断记录见 `pds/inference_limit.json`、`pds/per_slot.console.log`。所有安装资料、参考目录保持只读，生成项目和日志位于 FPGA 开发区。
