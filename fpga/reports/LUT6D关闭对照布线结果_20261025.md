# LUT6D 关闭对照布线结果（2026-10-25）

本报告执行 `fpga/reports/LUT6D关闭对照布线交接_20261025.md` 的唯一变量对照：在旧 L 的同一 MAP 网表上从头布局，关闭布局阶段 `logic_optimize_enable`，检验其对 Route-0008 与拥塞的影响。**结论：关闭后更差——更早触发原生 `Route-0008`，每轮未布通更多、单轮更慢，CLMA/CLMS 块占用从 90%/92% 升到 94%/95%。默认开启 LUT6D packing 对物理实现有益。** 本实验未生成位流，未下载、烧录或改 eFuse。

## 6. 结论与边界

1. **关闭 LUT6D packing 没有改善布线**：块占用更高、未布通更多、失败更早。默认 ON 应保留；本对照支持“LUT6D packing 对物理实现有益”的结论。
2. 该结果只说明物理实现差异，不能据此认定任何功能优化/原语存在缺陷；没有做优化后网表的等价仿真或板级复现。
3. 开关关闭不会撤销综合阶段已产生的 LUT6D；60% 面积候选不进入本次实验。
4. 仍未签核：无正式 routed DB、无 min/max STA、无位流；综合 DDR setup −1.337 ns、厂商 hold/removal、外部 DVP/RGMII/DDR/TMDS、33 条共享管脚告警、MCU 标定与真实 1080p30 吞吐/功耗/HDMI 身份均未改变状态。
5. 按交接第 7 步：临时路由许可已关闭，`bitstream_generation_allowed` 保持 false；运行结束后无 PDS 进程；运行结束残留的 native 锁经确认 owner_pid 109996 已不存在后归档到 `stale_lock/` 并清理，未删除活跃锁。
