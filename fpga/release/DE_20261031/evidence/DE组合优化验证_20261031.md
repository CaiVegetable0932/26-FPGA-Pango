# D＋E组合优化验证

本轮D＋E＋既有camera CDC修正的功能证明、SYN/MAP和独立约束核验完成。候选具备进入后续物理评估的依据，但没有启动PnR，也没有布线后STA、位流或实板验收。

本次以已验证BE为基线，只替换`rtl/control/raw_pose_solver.sv`为D的本地安装矩阵读取实现。E的RAW整32字节块优化、固定灰度、排空换矩阵、旧帧保持、原始pitch/yaw解算及既有时序约束均保留。验证全过程使用独立冻结目录，不修改旧BE构建。

SYN为`board_20261031_200204_931096`，MAP为`board_postsyn_20261031_201436_865573`。两个原生阶段退出0，源清单327项完全一致；10条post-SYN SCF实际加载，CCR零错误、33条既有ConstraintEditor-2002 share-pin诊断，无新增STA-3015。camera ready_sync/active→paused_meta的两条精确约束在DMR实际出现，后级paused_sync不新增例外。

综合报告仍有DDR同步hold估计：同域−0.006ns、OSERDES相关−1.138ns、DQS gate相关−2.374ns。SYN阶段phase FSM removal估计−4.059ns与后续MAP加载的10条复位SCF属于不同阶段。全部8个setup组非负不等于全芯片时序通过；必须以后核查实际routed min/max STA。clk_27m和camera_pclk的setup估计分别较BE少约0.122/0.120ns，但仍为+31.561/+4.173ns；不得写成所有时序数值完全相同。

## 真正实现的结构收益

DE综合网表中`pose_control/solver/left`实际推断为16×32存储，16个`GTP_RAM32X2DP`实例left_0～left_15均已核对。只使用地址0～8的九个系数；计算前完整写入，不能依赖RAM上电初值或复位清零。

包含子模块的SNR统计：solver由BE的2938 LUT/2115 FF/0 distributed RAM降至2624 LUT/1821 FF/16 distributed RAM，即局部−314 LUT/−294 FF。全板差值还有其它映射变化，不能全部归因为某288位数组。

E特化在DE中仍保留：raw_dma_reader和dma_byte_unpack中chunk_bytes/chunk_size/held_bytes/valid_bytes符号均已消除；reader为263 LUT/655 FF，unpack为46 LUT/300 FF（已包含在reader内，不能重复相加）。这只能证明网表结构，不能证明物理拥塞一定下降。
